## サムネイル

`npx tsx scripts/make-thumbnail.ts` で `recordings/thumbnail/` に3案（1280×720、PNG と JPG。Git に入れない）。A 案の顔は `recordings/author/portrait.jpg`（作者の写真。Git に入れない）から切り出す（`--photo none` で置かない）。YouTube には JPG（2 MB まで）を上げる。自分で作ったサムネイルを付けるには、YouTube の電話番号による確認が済んでいること。

| 案 | 絵 | 向き |
|---|---|---|
| **A-効かない**（作者が採用、2026-11-08） | 2050年に手札がはじかれる盤面の上に「抗菌薬が、効かない。」、ロゴ、一言、細菌のドット絵。右上に作者の写真（`recordings/author/portrait.jpg`）の顔を丸く小さく | 動画の冒頭の一言と同じ。小さく表示されても読める字が4文字×2行。顔は作者の求めで足した |
| B-現在と未来 | 「現在：楽勝（守り切った！）」と「未来（2050年）：効かない（膀胱が破られた）」を斜めに並べる | ゲームの仕組み（選択の結果が未来に出る）が一目で分かる。字は少し小さい |
| C-作者 | 作者の顔（シーン3の映像のコマ）とロゴ、「薬剤師がつくった 抗菌薬の教育ゲーム」 | 顔が入ると再生されやすいが、顔を出すかは作者が決める |

A を推す理由：動画の冒頭（0:00〜0:06）と同じ場面と言葉なので、押して開いた人が裏切られない。文字が大きく、スマホの一覧でも読める。

## 上げたあと

1. 1080p の処理が終わるまで待ち、ログアウトした状態か別のアカウントで再生して、音量（始まりのシーンと後半が同じ大きさ）と字幕（日・英）を確かめる
2. README の冒頭の3つのリンクの上に「- **デモ動画（3分）**：https://youtu.be/…」の行を足す
3. 提出フォームに URL を書く（20:00 まで。締切後は差し替えできない）
