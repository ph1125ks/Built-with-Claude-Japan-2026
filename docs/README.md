# docs/ の読み方

開発の記録と、動画・評価の文書を置くフォルダ。審査や評価で見るなら、上から順に。

| 読む順 | ファイル | 中身 | 向いている人 |
|---|---|---|---|
| 1 | [DEVLOG.md](DEVLOG.md) | 開発の記録。11/2〜11/8 の試行錯誤と判断を日付つきで残した（冒頭に「読み方」と節目の一覧）。ボットの比較の表、データ監査、試遊で直したこと、作者の判断 | 「深さと実行力」を見る人 |
| 2 | [eval/](eval/README.md) | 評価の記録3つ：すべての人に伝わるか（10人の評価役）、作者の物語が伝わるか（台本の版ごと）、スキル `stage-design` あり・なしの比較（本物の Claude で各3回） | 「Claude の活用」「インパクト」を見る人 |
| 3 | [DEMO.md](DEMO.md) | デモ動画（3分）の台本。第1版から第8版までの変わり方と、各シーンのナレーション・画面・時間配分 | 動画の作り方を見る人 |
| 4 | [PLAIN-LANGUAGE.md](PLAIN-LANGUAGE.md) | 平易な言葉の決めごと。動画・ゲーム・「はじめての人へ」で同じ言葉と順番を使うための台帳（医学的な言い回しは作者が確かめる） | 言い回しの根拠を見る人 |
| 5 | [YOUTUBE.md](YOUTUBE.md) | YouTube に上げるときの題名・概要欄・タグ・サムネイルの案 | — |
| 6 | [HANDOFF.md](HANDOFF.md) | 引き継ぎメモ。次のセッションの Claude Code が最初に読む。何回目のセッションで何をしたかの要約 | 作業の進め方を見る人 |
| — | [media/](media/) | README に貼った画面写真と GIF（ゲーム・結果画面・教員モード・はじめての人へ） | — |

仕様は [../SPEC.md](../SPEC.md)、データの出典と加工は [../data/README.md](../data/README.md)、スクリプトの一覧は [../scripts/README.md](../scripts/README.md)。

## 文書の約束

- 日本語で書く（[../CLAUDE.md](../CLAUDE.md)）。専門用語は、初めて出るところで平易な言い換えを添える（PLAIN-LANGUAGE.md）
- 「作者の判断」「作者の希望」と書いてあるところは、作者（薬剤師）が AskUserQuestion（選択肢付きの質問）に答えて決めたこと。それ以外は Claude Code の判断
- 主催のセッションや Discord の記録、作者の私的な事情は、ここには書かない（読むだけ。公開リポジトリのため）
