# 評価：薬学部4年生（22歳、実務実習の前）

## 1. 心に残ったこと・一言紹介

メロペネムを連打して楽勝だったのに、2050年に自分が残した菌に負ける流れ。並べ比べの「切り札 100% → 3%」で守れた差も残った。
友だちには「抗菌薬のタワーディフェンス。切り札ばかり使うと、25年後に自分が育てた耐性菌に攻められる。実習前にやっとこう」と言う。

## 2. 作者の話を聞いて

「若い人は広い薬を選ぶ」には一瞬ドキッとした。自分も迷ったらメロペネムを選ぶと思う。ただ、すぐに「つけが回るのは何年も先だから」と理由が続き、作者も2年目は手探りだったと話すので、責められている感じはせず、うなずけた。シーン4の画面にある「外して悪くなるのが怖い」を声でも言えば、もっと自分ごとになる。

## 3. 遊んでみたいか

遊んでみたい。持ち帰れそうなのは、グラム染色 → 菌名 → 感受性の順に分かることが増える流れ、正体が分かったら狭い薬に替える考え方（CTRX が効かない大腸菌に CMZ）、腸球菌にセフェムがもともと効かないこと。実習で MEPM を見たら「培養の結果は出たか」を確かめる癖がつきそう。

## 5. 冒頭について

半分引き込まれ、半分混乱した。MEPM の字は読めたので「連打で勝って、あとで負けた」は追えたが、早送りの画面で何が起きたかは分からない。「10年見てきた現実」が何の現実かも、シーン3まで分からなかった。それでもシーン6で同じ場面が戻り、全部つながった。謎としては効いている。

## 6. しくみとやり直し

抗菌薬・切り札・選択圧は講義の復習としてよく分かった。シーン4の菌の数（効く17・効かない3 → 0・20）は講義より分かりやすい。
やり直しで変えたことは、原則と数字では分かった。でも、どの瞬間に何から何へ替えたのかが画面で見えない。最初は切り札を使い、名前が分かってから替えたのか。残りの 3% は何に使ったのかが知りたい。

## 7. 直すとよい点（重い順）

1. **シーン7で切り替えの瞬間を見せる**：中ほどで菌の名前が出て、切り札から CMZ に替える場面を等倍で2〜3秒、矢印つきで。並べ比べは4秒以上に（シーン8・9を削る）。
2. **ゲーム画面の上の字幕を短く**：シーン5・7の2行を「遠く：色と形 → 中ほど：名前 → 近く：効く薬」の1行にし、出典は下に小さく。
3. **エンドカードを長くして QR を置く**：遊びたくなったところで URL が消える。5秒以上にし、大きな QR を1つ。
