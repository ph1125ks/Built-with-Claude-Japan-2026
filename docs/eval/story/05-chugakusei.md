# 評価：中学2年生（14歳、ゲーム好き）

## 1. 心に残ったこと

強い薬を連打して楽勝してたら、未来で「自分が残した細菌」に負けるのが心に残った。友だちには「細菌と戦うタワーディフェンスで、強い薬ばっかり使うと2050年にボコボコにされる。最初に負けた理由が後で分かるのがいい」と言う。

## 2. 作者はどんな人で、なぜ作ったか

病院の薬剤師の沢田さん。入って2年目に、専門のお医者さんがいない病院でチームを任されて、手探りだった。強い薬を使うと効かない細菌が増えるけど、困るのは何年も先なので、教えても伝わりにくい。だからゲームで早めに失敗できるようにしたんだと思う。

## 4. 最初の負ける場面

左の「膀胱」を守っていて、破られて負けたのは分かった。でも、なぜ負けたのか、「切り札」や「2050年」が何かは分からなかった。「楽勝だったはずなのに。」で「え、なんで？」となり、続きは見たくなった。

## 5. 「耐性」「選択圧」で変わるもの

最初は、人の体が薬に慣れて効かなくなることだと思っていた。シーン4の絵で、変わるのは細菌のほうだと分かった。薬で効くやつが倒れて、もともと少しいた効かないやつだけが残って増える、ということだと思う。

## 7. 遊んでみたいか・直すとよい点

遊んでみたい。自分のせいで未来の敵が強くなるのは、ほかのタワーディフェンスにない。

1. 最初の場面で「ピンクの棒＝守るもの、来るのが細菌」と一言ほしい。
2. カードの英字が多すぎる。強い薬かどうかを色やマークで見せてほしい。
3. シーン8・9は大人向けで長い。遊ぶ場面を増やしてほしい。
