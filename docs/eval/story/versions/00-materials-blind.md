# デモ動画の台本 5案（伏せて比べる用）

教育用タワーディフェンスゲーム「センタクアツ」（抗菌薬の選び方を学ぶ。細菌が膀胱に押し寄せ、手札の抗菌薬で守る。ステージ1「いま」→ ステージ2「2050年」。ステージ1で切り札の薬ばかり使うと、効かない細菌が残って2050年に負ける）の、3分のデモ動画の台本です。ハッカソン（Built with Claude: Japan 2026）に提出します。

主催の案内（原文の要点）：
- デモ動画は3分以内の日本語動画で、**実際に動いているところを中心に**紹介すること
- 動画で紹介するのは、期間中に作った機能・コードに限る

5つの案は、どれも同じゲームの台本です。順番に意味はありません。どれが新しい・古いかは伏せています。

各シーンの表記：`時間 ｜ 画面 ｜ ナレーション（声）`。「字幕」は画面に大きく出る文。
