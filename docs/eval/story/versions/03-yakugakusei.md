# 読み手3：薬学部5年生の感想（台本5案を伏せて一度だけ見た）

## 立場

- 薬学部5年生。抗菌薬の講義（作用機序、スペクトル、耐性菌、AMR アクションプラン）は受けた。病院実習はまだ。実際に抗菌薬を選ぶ場面は知らない。
- 実習先の先生から「見ておいて」とリンクをもらった、という気持ちで、頭から一度だけ通して見た（読んだ）。
- 見る前に思っていたこと：「どんなゲームか」「自分の勉強に役立つのか」を知りたい。作者の経歴や開発の裏側は、正直あまり興味がない。

## 案A

### 採点の理由

- **流れの一貫性 4**：冒頭の負け場面が 1:37 で「最初の場面は、こうして生まれました」と回収され、終盤の「あのころの私のように」も冒頭の話に戻ってくる。輪が閉じている。ただし 0:08 で作者の話に入り、0:26 でいきなり世界の死亡者数に飛ぶところで一度切れる。
- **頭に入りやすさ 3**：ルール（膀胱を守る、切り札を温存する）と教訓は言える。ただ、作者の個人史と「これは私が10年見てきた現実を早回しにした未来です」という文が最初にあって、ゲームの話に入る前に考えさせられてしまう。
- **遊びたくなるか 3**：ゲームが本格的に動くのは 1:24 から約40秒。やり直しの並べ比べが3.5秒で、2枚の結果を読み比べる前に次へ行ってしまう。
- **学びとして納得 3**：説明の紙芝居（0:58〜1:24）は「抗菌薬は細菌を倒す薬」「選択圧」と、講義そのまま。やり直しの薬の例（CTRX が効かない大腸菌 → CMZ）は字幕だけで、「なぜ CMZ なのか（ESBL）」が声で言われない。カルバペネム温存という言葉も出ない。

### 飛ぶ・散らかる・頭に入ってこない箇所

- **0:08–0:26**：負け場面の直後に作者の写真が寄ってきて、18秒の自己紹介。「10年見てきた現実を早回しにした未来」は、一度聞いただけでは「現実なの？未来なの？」と引っかかる。右の経歴カード（論文11本・招待講演・学会の賞・資格）を読みながら「入職2年目で…手探りでした」を聞くので、目と耳が別のことをしている。まだゲームが何かも分かっていないので、「手探りでした」の次に何が来るのか見えない。
- **0:26**：「手探りでした。」→ 「対策をとらなければ、2050年…」と、個人の話から世界統計へ飛ぶ。
- **0:37–0:58**：「教えても、選ぶ場面では広い薬に手が伸びる」は先生側の視点。学生の自分には「自分のこと」として入ってこない。「切り札」の定義は小さい補足だけ。
- **0:58–1:24**：③「遠く＝顕微鏡の色と形、中ほど＝名前、近く＝効く薬」は絵だけで声がない。あとで 1:51 に「正体が分かったら」と言われても、「どうやって分かるの？」が残る。
- **1:51.5–2:05.5**：並べ比べ3.5秒は短い。
- **2:38**：作者の写真が2枚目。自己紹介が2回あるように感じる。

### 経歴の出し方

位置が早すぎて長い。ゲームを見る前に18秒の人物紹介が来ると「先生の自己紹介が長い動画」という第一印象になる。「専門医のいない病院でチームを任された、手探りだった」という話そのものは、実習前の自分には響く（自分も手探りになりそうだから）。だから、この話は短く終盤に置いて「あのころの私のように」で回収する形のほうが、学生には届く。カードの受賞・論文数は、学生の目には「すごい人」より「審査員向けの箔」に見える。

## 案B

### 採点の理由

- **流れの一貫性 3**：問題 → 作者 → 説明 → ゲーム → 回収 → やり直し、の骨格は通っている。ただ冒頭に字幕が2本、途中で話し手が三人称（作ったのは…薬剤師で）から一人称（私の研究テーマ）に変わり、教員モードで補足が3行出るなど、ところどころ情報が重なって散らかる。
- **頭に入りやすさ 2**：声が1割速く、字も多い。0:17〜0:37 の図は文字ブロックが5つあって、速い声と同時に読めない。一度見ただけだと、骨格は分かるが細部が流れてしまう。
- **遊びたくなるか 4**：やり直しが23.5秒と長く、「切り札の連打より、確かに大変です。その代わり、2050年になっても、使える抗菌薬がたくさん残ります」の一言がいい。「大変だけど意味がある」と言われると、やってみたくなる。ステージ1の結果画面「切り札 3%」も目標になる。
- **学びとして納得 4**：「なら、切り札だけ使えばいい？」の問いかけから「切り札さえ効かない細菌が増える」へ行く流れは講義の復習として退屈でない。ESBL 産生菌が字幕に出るので、CTRX → CMZ の理由が自分の知識とつながる。ただ「間違った使い方でも、いまはよくなる」の「間違った」は、原因菌が分からない初期に広い薬を使うのは間違いではないと講義で習ったので、少し引っかかる（D の「効いているからと続きがち」のほうが正確に感じる）。

### 飛ぶ・散らかる・頭に入ってこない箇所

- **0:00–0:06.5**：声なしで6.5秒のあいだに、大きい字幕「抗菌薬が効かない。それが、耐性菌感染症。」と小さい字幕「楽勝だったはずなのに。」の2本。ゲームの負け場面を見ながら2本は読めない。大きい字幕のほうは講義で知っていることなので、「楽勝だったはずなのに」だけのほうが刺さる。
- **0:17.5–0:37.5**：図の文字（見出し、左、右、矢印、下）と5文の速い声がぶつかる。
- **0:37.5–0:55.5**：「作ったのは、博士号と…薬剤師で」と第三者が紹介しているように聞こえるが、1:25 で「私の研究テーマ」と言うので、誰が話しているのか一瞬迷う。
- **0:55.5–1:25.5**：30秒の説明を速い声で。問いかけは良いが、塊として長い。
- **2:17–2:33**：画面は Claude の作業記録、補足は「数値は公開データのまま」「肺炎など別の感染症にも」「最後は専門家が確かめて」の3行、声は別のことを言っている。16秒で全部は追えない。

### 経歴の出し方

位置（問題を聞いたあと）と長さ（10秒）はよい。「博士号と感染症の専門資格を持つ薬剤師で、病院で10年以上」は事実だけで、学生には「信用していい人なんだな」で済む。名前を声で言わないのは、カードに出ているので気にならない。ただ三人称で始めて一人称に変わるのが少し変。

## 案C

### 採点の理由

- **流れの一貫性 3**：グラフ → 作者 → 長い説明 → ゲーム → 教員モード、と並んではいるが、冒頭の3秒の負け場面が後で回収されず、説明が34秒、教員モードが34秒と、二つの長い塊で間延びする。
- **頭に入りやすさ 3**：1:01 で「細菌の正体は、近づくほど分かってきます」とゲーム画面でルールを言ってくれるのは分かりやすい。ただそこまでの1分は、講義で見たグラフと講義で聞いた説明なので、気が緩む。
- **遊びたくなるか 3**：ゲーム時間は約61秒とまあまあ。だが、やり直し（1:43〜1:59）が全部早送りで、「薬を替える瞬間」が見えない。合う薬の例も字幕だけ。

### 飛ぶ・散らかる・頭に入ってこない箇所

- **0:00–0:12**：グラフが先。講義の最初のスライドと同じなので「また1,000万人か」と思う。終わりの3秒の負け場面は短くて、何が起きたか分からないまま次へ。
- **0:12–0:27**：「学生や新人がこれを実践的に学ぶ機会は」の「これ」が何を指すのか、直前がタイトル画面なので一瞬迷う。
- **0:27–1:01**：34秒の説明。「かぜはウイルス」でいったん集中が切れる。ゲームが本格的に始まる 1:01 まで、動いているゲームは3秒しか見ていない。
- **1:43–1:59**：やり直しが早送りだけで、何をどう替えたのかが画面で追えない。
- **1:59–2:33**：教員モード34秒、6文。学生の自分にはいちばん関係が薄い部分がいちばん長い。
- **2:33–2:43**：「知識のメモ、確認係の AI、見張り」が何を指すのか分からない。
- **2:43–2:57**：「抗菌薬を受け取る人の理解にもつながります」は、話が患者さん側に広がって締めがぼやける。

### 経歴の出し方

7秒で名前と役割だけ。学生としてはこれで十分。「病院で抗菌薬の使い方を支える薬剤師」で、自分の将来の仕事の一つだと分かる。ただ、「これ」の指示があいまいなので、「抗菌薬の選び方を」と言い切ってほしい。

## 案D

### 採点の理由

- **流れの一貫性 5**：負け場面 → なぜ大事か（1,000万人）→ なぜ起きるか（効いているから続きがち、何年もかけて返る）→ 誰が作ったか → ルール → ゲームで再現 → 「最初の場面はこうして生まれました」→ やり直し → 先生向け → 締め。順番に理由があって、飛ぶところがない。
- **頭に入りやすさ 4**：一度見て、ルールと教訓は言える。欠けているのは、③「近づくほど分かる」が絵だけで声がないこと。あとで「正体が分かったら」と言われたとき、どう分かるのかが説明されていない。
- **遊びたくなるか 3**：ゲーム時間は約48秒で5案の中でいちばん短い。薬を替える瞬間が等倍で、並べ比べも5秒あるので、見せ方は丁寧。ただ、どの薬を使っているかを声で言わないので、「自分も選んでみたい」までは行かない。
- **学びとして納得 4**：「効いているからと、切り札の薬が続きがち。耐性は目に見えにくく、何年もかけて返ってくるから」は、講義で聞いた「デエスカレーションがなかなかされない」理由として納得できる。ESBL 産生菌が字幕にある。ただ説明の紙芝居（0:59〜1:25）は講義の繰り返しで、ここだけ退屈。

### 飛ぶ・散らかる・頭に入ってこない箇所

- **0:59.5–1:25.5**：「抗菌薬、いわゆる抗生物質は、細菌を倒す薬」から始まる26秒。知っている話なので、ここで集中が落ちる。③の距離ルールを声で言ってほしい。
- **1:25.5–1:39**：「切り札を連打」だけで薬名が出ない。字幕でもいいので「メロペネム」と見せてほしい。
- そのほかは「なし」。教員モードも21.5秒で、我慢できる長さ。

### 経歴の出し方

位置がいちばん自然。「なぜこの問題が大事か」を聞いたあと、「で、誰が作ったの？」と思うタイミングで出てくる。長さも約12秒（カードは丸い小さい顔写真）で、重くない。「作ったのは、薬剤師の沢田です。博士号と…10年以上」は事実だけで押しつけがましくない。直後に「〜ゲームにしました」と一人称になるのは、B ほど気にならないが、「薬剤師の沢田です」と一人称で始めてもいいと思う。

## 案E

### 採点の理由

- **流れの一貫性 4**：グラフ → 作者と目的 → ゲームの仕組み → 連打 → 2050年 → やり直し → 「ここからは教える側です」→ 開発 → 締め。一直線で飛ばない。減点は、冒頭がグラフで引きが弱いこと、終盤の教員モード39秒と開発16秒が長くて後半が沈むこと。冒頭の負け場面は3秒で、回収もない。
- **頭に入りやすさ 5**：説明の紙芝居がなく、0:34 からゲーム画面でルールを声で説明する。「遠くではグラム染色の見た目だけ。近づくと菌の名前、さらに効く薬が分かります」は、講義で習った「グラム染色 → 菌名 → 感受性」の順番そのままで、一度聞けば覚える。何を学べるかも、「カルバペネムを温存できる薬へ」とはっきり言われる。
- **遊びたくなるか 5**：ゲーム時間が約79秒で最長。3本のレーン、手札から薬を出す操作、メロペネム連打の結果画面（系統別の使用割合）、大腸菌に CTRX → 耐性が見えたら CMZ、腸球菌に ABPC という実際の手。「自分ならどう選ぶか」を考えながら見ていた。
- **学びとして納得 5**：「使った薬はカルバペネム系に偏り」「カルバペネムを温存できる薬へ」「第3世代セフェムが効かない大腸菌にはセフメタゾール、腸球菌にはアンピシリン」は、講義で習った ESBL・腸球菌のセファロスポリン自然耐性・カルバペネム温存とぴったり合う。補足「耐性化の速さは、ゲーム用に誇張しています」があるので、「1ステージで2050年が変わるのは言い過ぎでは」と思う前に先回りしてくれていて、信用できる。講義の繰り返しに感じる部分がない。

### 飛ぶ・散らかる・頭に入ってこない箇所

- **0:00–0:12**：グラフが先。C と同じで、講義のスライドと同じ絵から始まるので引きが弱い。終わりの3秒の負け場面は短すぎて意味が取れない。
- **1:27–1:50**：やり直しは丁寧だが、1回目と2回目の結果の並べ比べがない。「何がどれだけ変わったか」を一目で見たかった。
- **1:50–2:29**：教員モード39秒、6文、補足3行。学生の自分には関係が薄く、ここで「もう分かった」と思ってしまう。半分で足りる。
- **2:29–2:45**：「スキル」「エージェント」「フック」は分からない言葉。短いので我慢できる。
- 「選択圧」という言葉が声では出ず、補足「センタクアツ＝選択圧から」だけ。自分は分かるが、「これが選択圧」と一言あれば講義とつながってもっと気持ちいい。

### 経歴の出し方

5案の中でいちばん受け取りやすい。カード7秒で、声は「AST 薬剤師の沢田です」。AST は AMR アクションプランの講義で聞いた言葉なので、「ああ、病院で抗菌薬の使い方を見ている人だ」とすぐ分かる。そのあとすぐ「学生や新人が実践的に学ぶ機会はまだ少ない」と自分のことを言ってくれるので、「この人は自分に向けて作っている」と思える。資格の一覧はカードに出ているだけで、声で誇らないのがいい。

## 総合

### 1位：案E

理由：
1. 説明の紙芝居をやめて、ゲーム画面の上でルールを話す。講義で知っていることを聞かされる時間がなく、動いているゲームを見ている時間がいちばん長い。
2. 薬の名前と理由を声で言う（メロペネム連打、第3世代セフェムが効かない大腸菌にはセフメタゾール、腸球菌にはアンピシリン、カルバペネムを温存）。講義の知識と一対一でつながって「なるほど、実際はこう使うのか」と思えた。
3. 「耐性化の速さは誇張」の一言で、知っている学生ほど感じる「それは言い過ぎ」を先に潰してくれる。
4. 作者紹介が短く、「AST 薬剤師」「学生や新人に」と自分に向いている。

弱点：冒頭がグラフで引きが弱い。教員モード39秒が長く、見終わったときの印象を少し薄める。並べ比べがない。

### 2位：案D

理由：負け場面から始まって「最初の場面は、こうして生まれました」で回収する骨格が、5案の中でいちばん筋が通っている。問題 → 作者 → ルール → 再現 → やり直し、の順番に迷いがなく、作者紹介の位置と長さもちょうどいい。教員モードも21.5秒で我慢できる。

弱点：説明の紙芝居26秒が講義の繰り返しで、ゲーム時間が最短。距離ルール（近づくと分かる）を声で言わない。薬名を言わない。

A と B は同点だが、A は作者の話が早くて長く、B は速くて字が多い。C は説明と教員モードの二つの塊が長い。
