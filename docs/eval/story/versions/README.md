# 台本 第2〜6版の比べ直し：なぜ第6版は「頭に入ってこない」のか（2026-11-06）

きっかけは2つ。

- 作者が第6版の試作を見て「希望どおりに作られているのに、情報が頭に入ってこない。散らかっている、飛んでいる感覚がある」と言った
- 主催の最新の案内：デモ動画は3分以内の日本語で、**実際に動いているところを中心に**紹介すること。紹介するのは期間中に作った機能・コードに限る

ここでは、台本の第2版（受賞作の型）・第3版（すべての人に）・第4版（作者の物語）・第5版（問題から入る）・第6版（作者の8点の指摘）を、同じものさしで並べて見直す。各版の本文は git の履歴にある（第2版 d04bb17、第3版 ac548d4、第4版 6f345db、第5版 b97d228、第6版 34ea132 の `docs/DEMO.md`）。

## 3. 「飛んでいる」感覚の原因（第6版に起きていること）

作者の指摘8点は、どれも一つひとつは筋が通っていて、第6版はそのとおりに直っている。それでも頭に入ってこないのは、**部分の直しの積み重ねで、全体の形が変わったのに、全体を初見で通して見直す工程がなかった**ためだと考える。具体的には次の7つ。

### 3-1. 「ゲームにしました」と言ってから、ゲームが始まるまで 48秒ある

0:37.5 にタイトル画面で「そんな問題に対して……ゲームにしました」と宣言する。見る人は「どんなゲームか」を待つ。ところが続くのは、作者の写真と経歴（10秒）、そして「抗菌薬、いわゆる抗生物質は、細菌を倒す薬」から始まる紙芝居（30秒）。ゲームが実際に遊ばれるのは 1:25.5。**約束と実物の間に、別の話題が2つ挟まる**。これが「飛ぶ」感覚の最大の原因。

第2版・第3版は、名乗りの直後にゲームを遊び始めた（第3版は講義を挟むが、名乗りの前に「ゲームにしました」とは言っていない）。

### 3-2. 聞き手に求める知識の水準が、上がったり下がったりする

- シーン1〜2（0:06〜0:37）：「薬剤耐性」「抗菌薬を正しく使う」「耐性を広げない」を、説明なしで使う。**抗菌薬と耐性を知っている人向け**
- シーン4（0:55〜）：「抗菌薬、いわゆる抗生物質は、細菌を倒す薬」と、**ゼロから**説明し直す
- シーン7の補足（1:53〜）：「CTRX が効かない大腸菌（ESBL 産生菌）→ セフメタゾール（CMZ）」。**専門家向け**

30秒間、抗菌薬を知っている前提で話したあと、改めて「抗菌薬とは」から始まるので、聞き手は「今までの話は何だったのか」と一度リセットされる。

### 3-3. 語り手の立ち位置が、文ごとに変わる

| 時間 | 文 | 誰が話しているか |
|---|---|---|
| 0:06 | 「……という試算があります」 | 中立のナレーター |
| 0:37 | 「そんな問題に対して……ゲームにしました」 | 作り手（一人称） |
| 0:45 | 「作ったのは、……薬剤師で、」 | 作り手を**三人称**で紹介する誰か |
| 0:50 | 「……感染症の治療に携わってきました」 | 同じ文の後半で**一人称**に戻る |
| 1:20 | 「私の研究テーマで」 | 一人称 |
| 1:27 | 「試しに、切り札を連打してみます」 | 実演している人 |
| 2:33 | 「私が確かめました」 | 一人称 |

とくにシーン3の「作ったのは、博士号と感染症の専門資格を持つ薬剤師で、病院で10年以上、感染症の治療に携わってきました」は、主語（作ったのは＝薬剤師）が三人称なのに述語（携わってきました）が一人称で、**日本語として据わりが悪い**。第5版の「作ったのは、薬剤師の沢田です。博士号と……携わってきました」は、名乗りで一人称に切り替わるので自然だった。作者の指摘③（「作ったのは、薬剤師の沢田です」から始まるのは違和感）は順番の問題で、名前を外したことで文の形が崩れた。

### 3-4. シーン2の文が短く刻まれ、主語がない

> でも、間違った使い方でも、いまはよくなる。影響が返るのは、何年も先。だから、実感しづらい。

目で読めば分かるが、耳で一度聞くと、何が「よくなる」のか（患者？ 症状？）、何の「影響」か（耐性？）、誰が「実感」しづらいのか（医療者？ 患者？）を、聞き手が補わなければならない。第4版の同じ場所は「現場では、ほとんどの細菌に効く『切り札』が、効いているからと続きがち」で、場面が浮かぶ具体があった（元臨床医の評価役が「いちばん刺さった」と言った文）。第6版で抽象に寄せたのは、作者の指摘②（シーン4と重なる）を受けたためで、重なりは消えたが、**絵が消えた**。

第5版の評価でも、シーン2は「字だけで20秒続き、飽きた」（中学生）「誰の行動か迷った」（保護者）と、5人の中でいちばん弱い場面だった（心に残る 3.0）。第6版は同じ場面を、より抽象的に、より速く読む。

### 3-5. 同じ要素が何度も出てくる

- 「2050年」：シーン0（ゲーム）、1（試算）、6（ゲーム）、7（ゲーム、2回）。**5回**
- 「切り札」：シーン4で説明、5・7で使う。第5版まではシーン2にもあった
- 「選択圧」：シーン4（私の研究テーマ）、6（センタクアツ＝選択圧）
- 「学ぶ」：シーン2（学ぶ機会は多くない）、3（学べるゲーム）、10（教えられる人数）

とくに冒頭の伏線（シーン0「楽勝だったはずなのに」）を回収するのはシーン6（1:39）で、**その間 93秒に5つの話題**が挟まる。第4版の評価でも「シーン0の場面を覚えていない」人がいた。第6版は冒頭に大きなテロップ「抗菌薬が効かない。それが、耐性菌感染症。」を足したので、シーン0は「あとで種明かしする謎」ではなく「一般的な説明」として受け取られ、回収の効き目はさらに弱くなる可能性がある。

### 3-6. 密度：849字を 5.8字/秒で

第2版は 733字を平均 4.1字/秒で読む設計だった。第6版は 849字・最大 5.8字/秒。間（ま）がなくなると、聞き手は前の文を消化する前に次の文を聞く。「情報が頭に入ってこない」のは、構成の問題と同時に、**単純に速くて多い**ことの結果でもある。

### 3-7. 直し方の積み重ね

| 版 | 直しの動機 | 足したもの | 削ったもの |
|---|---|---|---|
| 第3版 | すべての人に伝わるように | しくみの講義 34秒 | 遊び方の声、教員モード 5秒 |
| 第4版 | 作者の物語を軸に | 負ける伏線 8秒、作者の写真 31秒、現場の話、時間のずれの図 | 講義 8秒、教員モード 12秒、やり直しの中身 |
| 第5版 | 私ごとすぎる → 問題から入る | 「正しく使う」の段、名乗りの前後 | 作者の物語、写真 2枚目 |
| 第6版 | 作者の8点 | テロップ、切り札の問いかけ、やり直し 9.5秒、肺炎の一言 | 教員モード 5.5秒、声の3か所 |

「指摘1つに直し1つ」を4回重ねた結果、**ゲームの前に「問題・なぜ・誰が・しくみ」の4つの説明が並び、Claude の見せ場が半分以下になった**。一つひとつの直しは正しかったが、合計の形を見た人がいなかった。

## 5. まとめ：何が良くて、何が失われたか

- **第5版・第6版で得たもの**：問題から入る順、身元の開示としての名乗り、冒頭のテロップ、シーン4の問いかけ、シーン7の見せ方。これらは残す価値がある
- **第2版・第3版にあって、いま失われているもの**：ゲームを早く見せる（0:34〜1:01）、しくみは遊びながら言う（第2版）か一本道の講義（第3版）のどちらか一つ、Claude の見せ場の厚さ（34〜39秒）、ゆっくりした声
- **第4版以降ずっと変わっていない弱点**：遊ぶ画面が 1:24 以降、図・写真が全体の半分、説明が 76〜79秒続く。第5版・第6版の直しは、この形の中で文を入れ替えたもので、形そのものは第4版のまま

主催の案内「実際に動いているところを中心に」に照らすと、第4〜6版の形（前半の半分を説明に使う）は、方向として合っていない。第6版の文の良さを、第2版・第3版の形に載せ直すのが、次の版の方向だと考える（具体案は「7. 次の版へ」）。
