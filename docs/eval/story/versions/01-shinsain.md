# 評価役1：ハッカソン審査員（ソフトウェア技術者、医療・薬学は素人）の読み

読んだもの：`materials-blind.md`（案A〜E、どれが新旧かは伏せられている）

読み方：初めて見る視聴者として、頭から順に一度だけ見たつもりで読んだ。重く見たのは次の4点。

1. 実際に動いているところが見えるか
2. Claude（AI）をどう使ったか
3. 3分で「何を作ったか」が伝わるか
4. 初見で話が頭に入るか

### 案A

- **流れ 3**：負ける冒頭 → 作者の身の上話 → 死亡者の棒グラフ → 概念図 → 紙芝居 → ゲーム、と前半で話題が4回変わる。「私が10年見てきた現実を早回しにした未来です」の橋渡しは良いが、「手探りでした」から「1,000万人」への跳びが大きい。
- **頭に入りやすさ 3**：声の速さは普通。ただし0:08〜0:26で、声は「入職2年目で手探り」と語りながら、画面の経歴カードは論文11本・受賞・資格を並べていて、声と画面が別のことを言っている。
- **動いている 2**：約40%。冒頭8秒のあと1:24まで、ゲームが説明の背景にしか出ない。
- **心に残る 4**：「専門医のいない病院で手探りだった人が、後進のために作った」という人物の物語は残る。ただ、作品より人物を覚えて帰る動画になっている。

### 案B

- **流れ 3**：「死亡者 → 正しく使うことが欠かせない → でも実感しづらい → 学ぶ機会がない → だからゲーム」という問題提起の筋道は、5案でいちばん論理的。ただその直後に作者紹介と30秒の紙芝居が挟まり、「ゲームにしました」からゲームが映るまで50秒待たされる。
- **頭に入りやすさ 2**：声が849字で1秒5.8字と速く、冒頭は大小2つの字幕と新しい語「耐性菌感染症」を声なしで6.5秒に詰めている。0:17.5の図は文字ブロックが6つ、2:17の教員モードは補足が3行。情報の密度が一度見るには高い。
- **動いている 2**：約42%。0:06.5〜1:25.5の79秒間、ゲームが本編として映らない。
- **心に残る 3**：「切り札の連打より、確かに大変です。その代わり、2050年になっても使える抗菌薬がたくさん残ります」の一文は正直で良い。速さで流されてしまうのが惜しい。

### 案C

- **流れ 4**：問題 → 作者 → 仕組み → 遊ぶ（仕組みの紹介 → 連打 → 2050年 → やり直し）→ 教える側 → 開発 → 使う場面、と筋がまっすぐ。教員モードに入る前の「効かない細菌の割合は、地域ごとに違います」は、A・B・Dにない良い橋渡し。
- **頭に入りやすさ 4**：798字で普通の速さ。1:01〜1:12で「近づくほど正体が分かる」を連打の前に見せるので、ゲームのルールが先に頭に入る。「変わるのは体ではなく、細菌のほう」も素人に効く一言。減点は34秒の紙芝居と、2:33の開発の図（4画面を10秒）。
- **動いている 4**：約53%。教員モードが34秒あり、Claude の仕事ぶりが見える。
- **心に残る 3**：教員モードは残る。冒頭が棒グラフ始まりで弱く、締めの一言「未来の耐性菌は、いまの一手で減らせる。」がエンドカード2秒にしかない。

### 案D

- **流れ 3**：Bの問題提起の筋道に、Aのゲーム場面を合わせた形。論理は通るが、0:06.5〜1:25.5が「図 → 図 → 経歴 → 紙芝居」と静止画4連続。0:40の「作ったのは、薬剤師の沢田です」は、まだゲームが紹介されていない段階で「作ったのは」と言うので、順序が逆に聞こえる。
- **頭に入りやすさ 3**：766字でいちばんゆっくり、字幕も1枚ずつで整っている。ただ0:18.5〜0:40の図は文字ブロック6つ＋補足1つで、Bと同じ密度。
- **動いている 2**：約39%で5案中最少。
- **心に残る 3**：並べ比べ5秒と、Claude の判断を等倍で4.5秒見せる工夫は良い。人物の物語はAより薄く、作品の印象もCほど強くない。

### 案E

- **流れ 5**：問題 → 作者と一言の問題提起 → すぐゲーム（ルール → 連打 → 2050年 → やり直し）→「ここからは教える側です」→ 開発 → 使う場面。場面の切り替えが少なく、ゲームが一続きの体験として見える。「ここからは教える側です」の一言で視点の切り替えが明示されるのは、5案でこれだけ。
- **頭に入りやすさ 4**：733字で最少、紙芝居なし、ゲームが自分で説明する。減点は専門用語：「グラム染色」「感受性」「カルバペネムを温存」「第3世代セフェム」が声に出てくる。また「選択圧」という語が字幕にしか出ず、声では一度も説明されない。
- **動いている 5**：約66%。主催の案内にいちばん忠実。
- **心に残る 4**：「守り切った！」の紙吹雪、Claude が「上限に近いので波を増やす」と自分で直す場面、フックがコミットを止めた画面。技術者として覚えて帰るものが多い。減点は、冒頭の負け場面との呼応や、大きな字の決め台詞がないこと。

## 3. 総合

**1位：案E（18点）**

理由：
- 主催の案内「実際に動いているところを中心に」に、唯一はっきり応えている（約66%）。
- 紙芝居を捨て、ゲームの最初の15秒でルールを見せ、連打 → 2050年 → やり直し、と一続きの体験として見える。初見でも「強い薬ばかり使うと、未来に何も効かなくなる」が絵で分かる。
- Claude の使い方が、他の案より具体的に見える。教員モードが39秒あり、Claude が「上限に近いので波を増やす」と自分で判断して直す場面をゆっくり見せる。開発の図も skill／agent／hook を名指しし、フックがコミットを止めた画面まで出す。技術者の審査員が「Claude をどう使ったか」を評価できる材料がいちばん多い。
- 直すなら2点。やり直しの声の専門用語を、A・Dの平易な文（「正体が分かったら、切り札は取っておき、その細菌に合う薬へ」）に置き換えること。「選択圧」を声で一度説明すること。

**2位：案C（15点）**

理由：
- Eに次いで動いている時間が長く（約53%）、教員モードが34秒ある。
- 「地域ごとに違う」→ 教員モード、という橋渡しがあり、流れが自然。連打の前に「近づくほど正体が分かる」を見せる構成も良い。
- 弱点は、冒頭の弱さ（棒グラフ始まり）、34秒の紙芝居、やり直しが全部早送り、開発の図が10秒で4画面。

**3位以下**：D（11）、A（12）、B（10）。合計点ではAがDを上回るが、Aは人物の印象、Dは作品の印象が残る動画で、ハッカソンの審査ではDの方向のほうが得点しやすい。この3案に共通する弱点は、冒頭のあと約80秒ゲームが映らないこと。Bはそれに加えて声が速く、字幕も多い。

## 5. 審査員として、どの案にも足りないこと

1. **「期間中に何を作ったか」の一言がない。** 主催は「期間中に作った機能に限る」と言っている。ゲーム本体も教員モードも期間中なのか、審査員は知りたい。冒頭か開発の場面で「この動画のすべては、期間中に Claude Code と作りました」と1文、または Git の記録に期間の目印を置くだけでよい。
2. **作品の一言説明が最初の15秒にない。** どの案も、何の作品かが分かるのは0:40〜1:00。審査員は何十本も見るので、「抗菌薬の選び方を学ぶタワーディフェンス。先生は Claude で地域のステージを作れる」を、冒頭の字幕かタイトル画面に一行で置いてほしい。
3. **教員モードの仕組みが、ソフトウェアとして見えない。** 「Claude がステージを作り、自分で試して直す」の「試す」は誰がやるのか（ボットが遊ぶのか）、入出力は何か（JSON のステージ？）、Claude Code なのか API なのか。工程の図があるなら、入力 → Claude（スキル＝設計の知識）→ ステージの JSON → ボットの試走 → 判定 → 直す、の一行があると技術者は納得する。「27% → 17%」も、何の割合かを声で一度言ってほしい（Aの補足にはあるが、声では言っていない）。
4. **等倍で遊んでいる時間がほとんどない。** ほぼ全部が早送りで、等倍は薬を替える一瞬だけ。ゲームの手触り（判断の間、操作のテンポ）が分からない。8〜10秒でよいので、カーソルの見える等倍の操作を1回入れてほしい。
5. **使ってもらった証拠がない。** 「使っていく場面」はどの案も予定の図。学生や同僚が1人でも遊んだ記録（一言の感想、プレイ回数、画面の前の手）があれば、「予定」が「実績」になる。
6. **いま触れるかが分からない。** URL と QR はエンドカードにあるが、「ブラウザで動く、インストール不要」など、審査員がすぐ試せる条件を言っていない。試してもらえる作品は、それだけで有利。
7. **作者の経歴が長い。** 医療の内容を信じてもらうための身元開示は必要だが、ハッカソンの審査員が見たいのは作品。10秒以内、カードは名前・資格・所属の3行に絞ってよい。Aの身の上話は心に残るが、作品の時間を削っている。
8. **薬の略号の字幕（CTRX・CMZ・ABPC・ESBL）は素人の審査員には雑音。** 入れるなら小さく、声では言わない。
9. **正直な限界の一言が、E以外にない。** Eの「耐性化の速さは、ゲーム用に誇張しています」は信頼を上げる。どの案にも1つは入れてよい。
