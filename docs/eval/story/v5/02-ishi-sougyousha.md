# 評価：審査員の一人、医療 AI スタートアップの創業者（元・臨床医）

対象：デモ動画 3分（台本 第5版の試作、2:59）。資料 `recordings/eval-story-v5/00-materials.md` と scene0〜11 のコマの一覧を見て評価した。

## 1. 心に残ったこと

「同じ細菌、同じ手札。ちがうのは選び方だけ」という1回目と2回目の並べ比べ（切り札 100%→3%、2050年に手札のどの薬も効かない細菌 12%→0%）は、ASP（抗菌薬適正使用支援）で私たちが口で説明してきた de-escalation の価値を、数字と負けの体験で見せていた。同業の人には「感染制御専門薬剤師が、自分の地域の JANIS の値で Claude にステージを作らせて、カルバペネムを使い続けると2050年に膀胱が破られるゲームを作った。研修医の勉強会にそのまま使える」と話すと思う。

## 2. 作者と、作った理由

- 作者：病院で10年以上、感染症の治療に関わってきた薬剤師（博士・感染制御専門薬剤師）。選択圧が研究テーマで、それがゲームの名前になっている。
- 作った理由：「効いているから切り札が続く」「耐性は何年も先に返る」ので、現場では一手の結果を確かめながら学べない。それを数分で、安全に失敗しながら学べるようにしたかった。さらに一人で教えられる人数には限りがあるので、教員モードで他の先生も地域の教材を作れるようにした。
- 経歴の出し方：自己アピールではなく、「身元を明かしてフェアに評価してもらう」ものに見えた。ナレーションは資格と年数だけで、論文数や賞はカードに静かに載っているだけ。問題提起（シーン1〜2）の直後に置かれているので、「なぜこの人がこの問題を語るのか」の答えとして自然につながった。医療の審査では、医学的な内容を誰が確かめたのかが最初の関心事なので、むしろありがたい。

## 4. 冒頭（0:00〜0:40）

引き込まれた。声なしで負ける場面から入り、「楽勝だったはずなのに。」で問いを立て、すぐに 1,000万人の試算で問題の大きさを示し、シーン2で「なぜ現場で直らないのか」に落とす流れは論理的で無駄がない。特に「効いているからと、切り札の薬が続きがち」は、臨床医なら誰でも身に覚えがある（患者が良くなっているのに de-escalation しない）ので、問題が自分ごとになった。
弱いのはシーン0の画面の情報量で、初見ではゲームの盤面が何を表すか分からないまま6.5秒が過ぎる。ただ、シーン6で同じ場面が回収されるので、最後まで見れば意味は通る。問題の大きさは十分に伝わった。

## 5. 名乗り（0:40〜1:00）

- 経歴（博士・感染症の専門資格・10年以上）：ナレーションで言うのはこの3つだけで、ちょうどよい。信頼につながった。
- 論文・賞：カードに文字で載るだけなので、自慢には見えない。読む人だけが読む、という扱いで適切。
- 小さな丸い写真：白衣で、顔が小さく控えめ。「本人が現場の人である」ことは伝わり、押しつけがましさはない。
- 長さ：カードは約11秒、全体で19.5秒（後半はタイトル画面）。これ以上長いと自己紹介に見え始めるので、今の長さが上限。カードの文字（所属・論文数）は小さいので、読ませるつもりがないなら今のままでよい。

## 6. 医学的な言い回しで引っかかる点

- 「2050年には、年間1,000万人が亡くなる。がんを超える、という試算があります」：「試算があります」と言っているので言い過ぎではない。ただ、この数字は2014年の O'Neill レビューのもので、方法論への批判もある。医療の審査員の多くは、2024年の GBD（Lancet）の推計（2050年に直接の死亡 約190万人、関連する死亡 約820万人）を知っている。図の「いまの薬剤耐性 70万人」も2014年時点の値で、今の推計（2021年に直接の死亡 約110万人）より小さい。図の副題に出典はあるが、「2014年の試算」と分かる書き方を棒のそばに足すと、突っ込まれにくい。
- 「効いているからと、切り札の薬が続きがち」：臨床の実感と合う。むしろこの動画でいちばん正確で鋭い一文。
- テロップ「切り札＝ほとんどの細菌に効く薬（カルバペネム系など）」：一般の人向けの言い換えとして許容できる。厳密には「切り札」は最後の手段（コリスチンなど）を指すこともあるが、カルバペネムを温存すべき薬として扱うのは日本の ASP の文脈で自然。
- 「耐性は目に見えにくく、何年もかけて返ってくるから」：集団の耐性率としては正しい。ただ、広域薬の害はその患者自身にも数日〜数週間で返ってくる（耐性菌の保菌、C. difficile 感染など）。「何年も」だけだと、臨床医には少し片側だけの説明に聞こえる。動画の尺では今のままでよいが、「はじめての人へ」のページで補えるとよい。
- 「一手の結果を確かめながら学ぶ機会は、多くありません」：その通り。処方の結果のフィードバックが届かないのは、臨床教育の本当の穴。
- 「合う薬の例：CTRX が効かない大腸菌 → セフメタゾール（CMZ）」：日本では ESBL 産生大腸菌の尿路感染症に CMZ を使う考え方が広まっており、国内の医療者には通じる。ただ、CTRX が効かない理由が AmpC の過剰産生なら CMZ は安定でないので、厳密には「ESBL を作る大腸菌の例」と書く方が正確。また海外の審査員には日本特有の選択に見える。
- 「膀胱炎を起こす細菌から、膀胱を守ります」：単純な膀胱炎は通常、内服でカルバペネムも点滴も使わない。ゲームの「乱用」の場面としてはそれ自体が誤用の例なので筋は通るが、臨床医は一瞬引っかかる。「尿路感染症（膀胱炎など）」とするか、ゲームの単純化であると分かる言い方にすると安心。
- シーン4「検査の結果が出るまで数日」「ウイルスには効かない」：正確。一般の人向けに大事な点を押さえている。

## 7. 4つの観点の見込み

- インパクト（30%）：強い。AMR は世界的な課題で、対象（新人・薬学生・医学生）と使う場面が具体的。地域のデータで教材を作れるのは、教える側が少ない現場への答えになっている。
- デモ（25%）：強い。負け → 種明かし → やり直しで守り切る、の流れと並べ比べの数字で、ゲームの価値が一度で伝わる。早送りの場面でテロップが読めない所だけが減点。
- Claude の活用（25%）：ふつう〜強い。Claude がステージを作り、シミュレーションで「切り札だけで守れてしまう割合 27%」を見つけて自分で直す、という検証のループは本物の活用。ただ画面の文字が小さく尺も短いので、審査員が気づかない恐れがある。
- 深さと実行力（20%）：強い。JANIS・EUCAST・薬価基準などの公的な値を作者が照合し、数値を Claude に作らせない設計、スキルあり・なしの評価まであり、医療 AI として信頼できる作り方をしている。

## 8. 直すとよい点（重い順）

1. **シーン8（Claude の検証ループ）を読める形にする。** 作業記録の全画面は文字が小さすぎる。「27% → 17%（上限 30%）」と「敵を増やした」の2点を大きく出し、工程の図（1〜5）を主役にする。時間は、シーン5の早送り（×23、8秒）から約2秒、シーン9のスキルあり・なしの表（5秒）から約2秒を取り、シーン8に足す（合計 +4秒、全体は 2:59 のまま）。シーン9の表は「試行錯誤 減った・139秒 vs 189秒」の1行だけにすれば3秒で足りる。
2. **シーン1の数字に年を添える。** 棒のそばに「2014年の試算」と小さく足す（時間は使わない）。余裕があれば、図の下に「最新の推計（GBD 2024）でも、2050年に関連する死亡は年800万人超」と1行添える。医療の審査員が最初に疑うのはこの数字なので、先に答えておくと信頼が上がる。ナレーションは今のままでよい。
3. **シーン5のテロップを短くし、医学的な表現を2点整える。** シーン5の上のテロップ（遠く・中ほど・近く…）は ×23 の上では読めないので、「近づくほど、細菌の正体が分かる」程度に短くする（JANIS の出典はシーン8・9で出ている）。あわせて、ナレーションの「膀胱炎」を「尿路感染症」にするか画面で「（ゲームの単純化）」と分かるようにし、シーン7のテロップを「ESBL を作る大腸菌（CTRX が効かない）→ セフメタゾール（CMZ）」にする。どちらも時間は増えない。
