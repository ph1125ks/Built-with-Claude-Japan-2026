# 評価：保護者（42歳、医療の知識なし）

評価した資料：台本 第5版の試作（2:59）。`recordings/eval-story-v5/` の資料と scene0〜11 のコマの一覧。

## 1. 心に残ったこと

いちばん残ったのは、ナイトが細菌を倒したあと、薬の効かない細菌だけが残ってどんどん増えていく絵（シーン4）と、「変わるのは人の体ではなく、細菌のほうです」の一文です。家族に話すなら、「抗生物質って、使うと“効かない菌”だけが残って増えるんだって。2050年には、それで亡くなる人ががんより多くなるかもしれないらしいよ。薬剤師さんがそれを学ぶためのゲームを作ってた」と言うと思います。ただ、「じゃあ、うちの子がもらう薬はどうすればいいの？」という答えは持ち帰れませんでした。

## 2. 作者と、作った理由

- 作者：病院の薬剤師（沢田さん）。博士号と感染症の専門資格があり、病院で10年以上、感染症の治療に携わってきた人。
- 作った理由：抗菌薬の選び方の結果は何年も先にしか出ないので、現場では学ぶ機会が少ない。それをゲームで、数分で、安全に失敗しながら学べるようにした。一人で教えられる人数には限りがあるので、勉強会や実習・講義で広げたい。
- 経歴の出し方：自慢には見えませんでした。「作ったのは〇〇です」と最初に名乗り、写真も小さく、話し方も淡々としているので、「誰が作ったかを先に明かしている」印象です。むしろ、医療の素人の私には「この話は信用してよさそうだ」と思う材料になりました。ただ、カードの下の行（論文11本・英文8本・学会の賞の名前）は字が小さく、読み切れないうちに画面が変わります。読めなかったので、自慢とも感じませんでした。

## 4. 冒頭（0:00〜0:40）

- 引き込まれたか：シーン0だけでは引き込まれませんでした。何のゲームか分からず、英字の略号が多く、「負けた」ことしか分かりません。引き込まれたのはシーン1の棒グラフからです。「年間1,000万人」「がんを超える」は、医療の知識がなくても重さが分かります。
- 自分ごとに感じたか：半分だけです。数字は怖いと感じましたが、シーン2の「正しく使う」が誰の行動なのかが分かりにくく、「親の私が何か間違えているのか」「お医者さんの話なのか」と迷いました。「切り札の薬が続きがち」まで聞いて、選ぶのは医療者だと分かり、そこで少し「自分の話ではない」と距離ができました。
- 子どもが中耳炎で抗菌薬をよくもらう親としては、「何年も先に返ってくる」は自分の子どもの将来の話として響く余地があります。それを一言つなげてもらえると、自分ごとになると思います。

## 5. 名乗り（0:40〜1:00）

- 信頼か自慢か：信頼できる人に見えました。病院の薬剤師で、10年以上、感染症の治療に携わってきた、という声の説明は分かりやすく、写真が小さく丸いので控えめです。白衣の写真も「病院の人」だと一目で分かってよいです。
- 経歴の中身：博士号は分かります。「感染症の専門資格」は声で聞くと分かりますが、画面の「感染制御専門薬剤師」「臨床薬剤疫学分野」は知らない言葉です。論文・賞の行は小さくて読めませんでした。読めないので、自慢にも、信頼の材料にもなっていません。
- 長さ：名乗りは約12秒で、ちょうどよいと感じました。これ以上長いと「この人の話」になってしまうと思います。

## 6. しくみ（1:00〜1:25）と見終わったあとの不安

- しくみは分かりました。「抗生物質は細菌を倒す薬」「ウイルスには効かない」「薬ごとに効く細菌が違う」「使うと効かない細菌だけが残って増える」の4つは、この動画で初めてはっきり理解できました。「選択圧」という言葉も、絵のおかげで分かりました。
- 不安は残りました。
  - 「ウイルスには効かない」と聞いて、「風邪のときにもらった抗生物質は何だったのか」と思いました。動画はそこに触れないので、もやもやが残ります。
  - 「正しく使う」のうち、親ができること（出された分を指示どおりに飲ませる、余った薬を自己判断で使わない、分からなければ医師・薬剤師に聞く、など）は一言もありません。「子どもに出た薬は飲ませていいのか」「途中でやめていいのか」の答えは持ち帰れませんでした。
  - 「切り札の薬」は悪者のように聞こえます。子どもが入院して切り札を使われたら不安になりそうです。「必要なときのために取っておく薬」だという言い方があると安心します。
- エンドカードの一言：「抗菌薬を受け取る人の理解にもつながる」は、私（受け取る側）に向けた言葉だと分かり、うれしく感じました。ただ、声がなく4秒で消えるので、半分しか届いていません。また「理解につながる」と言われても、何を理解すればよいのかは動画の中で示されていないので、言葉だけが浮いています。

## 7. 直すとよい点（重い順）

1. **受け取る側（患者・家族）への一言を、声で入れる。** エンドカードの一文を、シーン10の締めの声に入れるか、シーン11で読み上げる。例：「抗菌薬を受け取る人も、なぜこの薬なのかを知ることで、安心して使えるはず」。あわせて「出された薬は指示どおりに。迷ったら医師・薬剤師に」を画面の小さな字で一行添えると、見終わったあとの不安が減る。時間（約3秒）は、シーン9のスキルあり・なしの評価（5.0秒）を2秒に縮める、またはシーン8の後半（早送りの作業記録）から1〜2秒取る。
2. **シーン2の「正しく使う」を、誰の行動か分かる言い方にする。** 例：「耐性を広げないために欠かせないのが、病気に合った抗菌薬を選ぶこと」。「切り札」も「いざというときのための、ほとんどの細菌に効く薬」と言い換えると、悪者に聞こえない。時間は増えない（言い換えだけ）。
3. **ゲーム画面（シーン0・5）に、何が何かを示す一行を入れる。** 例：シーン5の冒頭に「兵士＝抗菌薬　ピンクの粒＝細菌　左の袋＝膀胱」。いまの上のテロップ（グラム染色・感受性・JANIS）は素人には読めないので、置き換えてよい。シーン0は声がないので、ゲームの説明はシーン5でよいが、英字の略号の多い下のカード列は少し暗くするなどして目立たなくすると、見る場所が分かる。時間は増えない。
