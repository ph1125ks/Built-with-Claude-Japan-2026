# 評価：薬学部4年生（実務実習の前）

評価した人物：薬学部4年生。授業で抗菌薬の分類（ペニシリン系・セフェム系・カルバペネム系など）と、耐性菌（ESBL 産生菌、MRSA など）は習った。グラム染色・感受性試験も言葉としては知っている。現場で薬を選んだことはない。

## 1. 心に残ったこと

「最初に負ける場面があって、2050年に膀胱が破られるんだけど、それが自分が切り札を連打したせいだった、って後で種明かしされるのがうまかった」と同級生に話すと思う。もう一つは、1回目と2回目の比べ方。「切り札を100%使った→2050年に負けた」「3%に抑えた→守り切った」。授業の“カルバペネムは温存”が、数字と結果でつながった。

## 2. 作者と、作った理由

- 作者は病院の薬剤師で、感染症の治療に10年以上かかわってきた人。研究テーマが「選択圧」で、ゲームの名前もそこから取った、と受け取った。
- 作った理由は「耐性は何年も先に返ってくるので、一手の結果を確かめながら学ぶ機会が少ない。だから数分で、安全に失敗しながら学べるようにした」。筋が通っていて、納得できた。
- 経歴の出し方は、**身元を明かしてフェアに評価してもらうものに見えた**。声で言うのは「薬剤師・博士号・専門資格・10年以上」だけで、論文数や賞は小さな字のカードに載っているだけなので、押しつけがましくない。むしろ「感染制御専門薬剤師」という資格が、将来の自分の目標の一つとして見えた。シーン9で「値はすべて公的な文書で私が確かめた」と言うので、名乗りが「中身に責任を持つ人」という意味になっていて、自己アピールより信頼につながった。

## 4. 冒頭（0:00〜0:40）

- 引き込まれた。負ける場面（なぜ負けたかは分からない）→ 1,000万人の試算 → 「正しく使う・結果は何年も先」の順で、「なぜ負けたのか」という疑問を持ったまま本題に入れた。
- ただ、シーン0の6.5秒は画面が細かく、カード名や略号が何なのかは読めない。「いま」「2050年」の2つの文字と、「楽勝だったはずなのに。」だけが頭に残った。それで十分だと思う。
- 「学ぶ機会が少ない」は**自分のことだと感じた**。授業ではスペクトルと耐性機序を覚えるだけで、自分が選んだ薬で何年後に何が起きるかを確かめたことはない。実習でも、選ぶのは医師で、結果を追いかける機会はほとんどないと思う。ナレーションの「効いているからと、切り札の薬が続きがち」は、現場の話として少しどきっとした。

## 5. 名乗り（0:40〜1:00）

- 経歴（博士・感染制御専門薬剤師・10年以上・論文・賞）は、「この分野の専門家が中身を作った」という保証として受け取った。「この人から学びたい」につながった。とくに、シーン4で「選択圧が私の研究テーマ」と言うので、経歴とゲームの名前が一本の線でつながる。
- 小さな丸い写真は、顔が分かる程度で控えめ。白衣なので「病院の薬剤師」であることがすぐ伝わる。
- 自慢には見えなかった。論文数と賞は声で言わず、小さな字にとどめているのがちょうどよい。
- 長さ：経歴のカードは約11秒、全体で約20秒。後半の8秒はタイトル画面と「何年も先の結果を数分で、安全に失敗しながら学べる」で、ゲームの説明に移っているので、長くは感じなかった。

## 6. 遊びたくなったか・学べそうなこと・分からなかった言葉

- **遊びたくなった**。とくに「1回目は切り札を連打して、2回目は合う薬に替える」を自分でも比べてみたい。
- 実習の前に遊ぶとしたら、学べそうなこと：
  - 経験的治療（原因菌が分からないうちは広く）から、菌名と感受性が分かったら狭い薬へ替える（デエスカレーション）流れ。
  - グラム染色 → 菌名 → 感受性、と情報が順に増えること。検査の結果が出るまで数日かかること。
  - 薬ごとに効く菌が違う（スペクトルの表）を、覚えるだけでなく使って確かめること。
  - カルバペネムを使い続けると、どの薬も効かない菌が残る（選択圧）こと。
  - 地域によって耐性率が違うこと（JANIS のデータ）。
- 分からなかった言葉・場面：
  - AHI、DASC/DOT、Access／Watch（結果画面。AWaRe は聞いたことがある程度）
  - 「AST の薬剤師」「EUCAST Expected Resistant Phenotypes」「スキル（知識のメモ）」（シーン9）
  - 「切り札を使い続けても、2050年を守れてしまう割合 27%→17%」（シーン8。何の割合で、なぜ下げるのか一度で分からない）
  - 略号：CTRX・CMZ・MEPM・IPM/CS は分かるが、CFDN・TAZ/PIPC・AMPC など、カードの略号を一瞬で全部読むのは無理
  - なぜ CTRX が効かない大腸菌に CMZ なのか（ESBL という言葉が出ないので、授業とつながりにくい）
  - シーン0の画面で何が起きているか（シーン6で種明かしされるまで分からない。ただ、これは狙いどおりだと思う）

## 7. 直すとよい点（重い順）

1. **シーン7の並べ比べ（1回目／2回目）を長く見せる。** いちばんの学びの場面なのに約3.5秒で、「100%→3%」「12%→0%」を読み終わる前に終わる。最低でも5〜6秒ほしい。時間はシーン9の後半（スキルあり・なしの評価、5秒）から2〜3秒取る。学生には何の話か分からない画面なので、短くしても伝わる量は減らない。
2. **シーン7の「合う薬の例」に一言だけ理由を足す。** 「CTRX が効かない大腸菌（ESBL 産生菌）→ セフメタゾール（CMZ）」のように、テロップに「ESBL 産生菌」を入れると、授業で習ったことと一致して「なるほど」になる。ナレーションは変えず、テロップだけなので時間は増えない。
3. **シーン5の上の帯（遠く・中ほど・近く）を、早送りの最初の数秒だけにするか、短くする。** 早送り ×23・字幕・帯が同時に出て、どれも読めない。同じ内容はシーン4の4枚目（遠く・中ほど・近くで分かること）で見ているので、帯は「遠く：グラム染色 → 中ほど：名前 → 近く：感受性」だけにして、「耐性率は国の公開データ（JANIS）から」はシーン8の「数値は国の公開データ（JANIS）のまま」に任せる。時間は増えない。
