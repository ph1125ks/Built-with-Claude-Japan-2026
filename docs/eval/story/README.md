## 効いていたこと

- **冒頭の負ける場面と、シーン6の回収**（5人全員）。冒頭は「何が起きたか分からないが引っかかる」（分かりやすさ 2.0・心に残る 4.0）で、シーン6で同じ場面に戻ったところで全員が腑に落ちた。いちばん心に残ったシーン（4.6）
- **作者の物語は本物に聞こえる**（審査員・元臨床医・薬学生）。「入職2年目、専門医のいない病院で、手探り」は、薬学生には2年後の自分と重なり、保護者は締めの「あのころの私のように」で冒頭とつながって「じんときた」。元臨床医には「効いているから変えにくい」がいちばん刺さった
- **時間のずれの図**（シーン3）は核心として伝わった（元臨床医 心に残る 5、審査員は「技術的負債と同じ形」）
- **しくみ**（シーン4）は第3版に続いて伝わった。保護者と中学生は「体が薬に慣れる」という思い込みが直った
- 元臨床医の審査の見込み：デモ・Claude の活用・深さと実行力は「強い」、インパクトは「ふつう」

## 直すとよい点（重い順。人数は報告の中の言葉から数えた目安）

1. **やり直し（シーン7）で、何を変えたら勝てたのかが画面で見えない。並べ比べが1.5秒で消える**（薬学生・保護者・元臨床医・審査員）。案：細菌の名前が出て切り札から合う薬に替える瞬間を等倍で2〜3秒、並べ比べを4秒以上。時間はシーン8・9から
2. **シーン8・9は速く、医療を知らない人や学生には遠い**（保護者・中学生・薬学生は分かりやすさ 1〜2）。一方、審査員は Claude の判断（27% → 17%）を1か所だけ等速で見せてほしい、スキルの評価をもう少し見たいと書いた。「守れてしまう割合」がなぜ悪いのか分からない（薬学生・保護者・中学生）
3. **言い回し**（元臨床医）：
   - 「教えても、若い人は選ぶ場面で広い薬を選ぶ」は、若い医師を責める言い方に聞こえる（薬学生は「一瞬ドキッとしたが、手探りの話があるので嫌な気持ちにはならなかった」）
   - 「そのつけが回るのは、何年も先」は半分しか正しくない（腸炎や耐性菌の保菌は数日〜数週で出る）
   - 「これは、私が10年見てきた現実の、少し先です」は、ゲームの中の注記「速さは大げさ」と食い違う
   - 重症なら広い薬で始めるのが正しいこともある。問題は、結果が出ても続けること、と一言ほしい
4. **2050年の試算**（元臨床医）：2014年の試算は根拠の弱さが批判されてきた数字で、比べているがんの死亡は当時の値。GBD（Lancet 2024）に替えて「がんを超える」を削る案。ほかの4人には分かりやすく、保護者・中学生には「がんより多い」がいちばん身近だった
5. **経歴のカードは履歴書のようで、少し自慢寄り**（審査員）。それより「10年見てきた現実」の具体的な一場面を一文で。字が小さく読み切れない（4人）
6. **エンドカードの 2.5秒では URL を読めない**（5人全員）。4〜5秒、QR を足す案。保護者は、エンドカードの「受け取る人の理解にもつながる」こそ自分のことなので、声で言ってほしい（「子どもに出た薬は飲ませていいのか」という不安が残った）
7. **早送りの画面に2行の補足の字幕が重なって読めない**（シーン5・7。薬学生・審査員）。シーン6の最後で大きな字が2つ重なる（薬学生）
