## 1. 最初の30秒で分かったこと
「このままだと、薬が効かない菌で死ぬ人が2050年にがんより多くなるかもしれない。だから抗菌薬をちゃんと使えるように、病院の薬剤師さんが、学生や新人向けに遊んで学べるゲームを作った。たぶん僕みたいな薬学生が対象」
→ 何の話か・誰のためかは伝わっている。ただ「ちゃんと使う（適正使用）」が抗菌薬では具体的に何をすることなのかは、この時点では分からない。

## 2. 分からなかった言葉
- **AST 薬剤師**（S1）：「抗菌薬の使い方を支える」とは言ってくれたが、何の略か、チームか資格かも分からない。
- **適正使用**（S1）：薬学で何度も聞く言葉。でも抗菌薬の場合に何をすることかは知らない。
- **グラム染色の見た目**（S2）：陽性・陰性は聞いた。画面のピンクの細長いのと紫の粒の列が、どっちなのかすぐ出てこない。見た目で何が分かるのかの説明もない。
- **ABPC・CMZ・CTRX・CAZ・MEPM など**（S2〜S5）：カードは略号が大きく、一般名は小さくて早送りでは読めない。声は「メロペネム」「セフメタゾール」なので、どのカードの話かつながらない。
- **Access / Watch・供給制限**（カード）：説明なし。
- **カルバペネム系**（S3）：「メロペネムを連打」→「カルバペネム系に偏り」。メロペネムがカルバペネム系だと知らないと、別の話に聞こえる。
- **AHI・DASC/DOT・Access 薬の割合**（S3 結果）：まったく分からない。
- **選択圧**（S4）：聞いたことがある気もするが、意味は言えない。画面は「名前の由来」としか言わない。
- **第3世代セフェム・温存**（S5）：セフメタゾールも「セフ」が付くのに、なぜ効くのか分からない。
- **JANIS**（S6）：分からない。
- **スキル・エージェント・フック・コミット・鍵**（S7）：プログラムをしないので分からない。「鍵」は何の鍵？

## 3. 置いていかれた所・疑問に思った所
- 0:12.8〜0:19.8（S1）：肩書きのカードが5行で7秒。字幕と両方は読めない。
- 0:36〜0:40（S2）：遠い・中ほど・近いで分かることが変わる理由。現実の何かと対応しているのか、ゲームの決まりなのか。
- 0:54〜0:59（S3）：×12 で声のない5秒。何が起きているのか見えない。
- 0:59〜1:09（S3 結果）：数字と表が多く、「耐性菌が増えた」がどの数字かを探すうちに次へ。
- 1:28〜1:40（S5）：菌名と薬名が数秒おきに来る。×13 の画面では、どのカードをどの菌に出したかが見えない。
- 1:40〜1:48（S5）：×25 で声がない。勝った瞬間（守り切った・紙吹雪）は、コマの一覧では見つけられなかった。
- 2:37.8〜2:45.5（S7）：声が「フック」と言うとき、画面はデータ照合の表。フックの画面が出たときには声が終わっている。

## 4. いちばん心に残ったこと
「押し寄せるのは、さっき自分が残した耐性菌です」。さっきの楽勝が、そのまま次の負けになる。膀胱が赤くなって 0/100 になるのは悔しいし怖い。「あなたの選択が、未来の敵をつくる」はタイトルとも合っていて覚えた。

## 5. そもそも説明が足りないと思うこと
- **なぜ「何にでも効く薬」を使うと耐性菌が増えるのか**。動画は「連打した→増えた」という結果だけ。「薬を使うと、その薬に負けない菌だけが生き残って増える」の一文がほしい。これがゲーム名の意味のはず。
- **「広く効く薬」と「狭く効く薬」の対比**。S3 の「ほとんどの菌に効く」と S5 の「温存できる薬」が対になっていると、自分では気づけなかった。
- **なぜ膀胱なのか**。膀胱炎の患者さん？
- **2050年の菌は誰の菌か**。同じ患者さん？病院全体？「自分が残した菌が25年後に来る」は現実ではどういう意味か。
- **なぜ地域のデータが大事なのか**。地域で効く薬が違う、という前提を知らない。

## 6. 後半の「教える側」は分かったか、すごさは伝わったか
「先生が地域と教えたいことを入れると、Claude がステージを作り、わざと乱暴に遊ぶロボットに何十回も試させる。乱暴でも勝てるなら難しくし直す。数字は AI に作らせず、最後は専門家が確かめる」――流れは分かった。右の工程の図と「27% → 17%」が助けになった。
すごさは半分。AI が自分で試して自分で直すのはすごいと思う。でも作業の記録は字が細かくて読めず、27% が何の勝率かも一瞬では分からない。「自分の地域のデータで」のありがたみは、地域で違う理由を知らないので伝わらない。S7 は「全部 Claude Code で作った」以外は分からなかった。

## 7. 遊んでみたいか・人に勧めたいか
遊んでみたい。抗菌薬の授業の前に、どの菌にどの薬かを体で覚えられそう。ドット絵もかわいいし、先に負ける体験があるのが良い。同級生にも勧める。ただ略号が多いので「難しそう」と引く人もいそう。「誇張しています」が何度も出るので、試験勉強にどこまで使っていいか少し不安。

## 8. こうすれば伝わる（優先順）
1. **選択圧を一文で言う**。S4 のテロップを「センタクアツ＝選択圧：薬が、効かない菌だけを生き残らせる力」に。S3 の「生き残った耐性菌」の前でも、同じ考えを声で言う。
2. **薬の名前を声と画面でそろえる**。声で薬名を言うときは、そのカードを拡大し「MEPM＝メロペネム（カルバペネム系）」と出す。最初に「何にでも効く切り札、メロペネム」と言えば、S5 の「温存」とつながる。
3. **結果は1つの数字だけ拡大する**。表全体ではなく「緑膿菌のメロペネム耐性 12%→28%」に矢印。S5 の最後に、1回目と2回目の結果を左右に並べる（膀胱の残り、耐性率、カルバペネム系の割合）。
4. **S5 の1場面を等倍で見せる**。「セフトリアキソンが効かない大腸菌」に CMZ を出して倒す所を止めて見せる。「第3世代セフェム」より、カードの薬の名前で言うほうが分かる。
5. **S2 に一言足す**。「膀胱炎の患者さんの膀胱を守る」「遠いほど分かることが少ない＝実際の検査で分かる順番と同じ」（もしそうなら）。
