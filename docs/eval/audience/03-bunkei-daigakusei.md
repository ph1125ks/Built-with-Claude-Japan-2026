## 1. 最初の30秒で分かったこと
（けんた）「薬が効かなくなって、2050年には1年で1,000万人が死ぬかもしれない。がんより多い。それで病院の薬剤師さんが、薬の正しい使い方を、医療の学生や新人が体験して学べるゲームを作った、って話ですよね。」

整理：何の話か・作った人・誰のためかは30秒で伝わる。残るのは3点。
- 「抗菌薬」が、知っている「抗生物質」と同じかが分からない。だから風邪でもらった薬の体験とつながらない。
- 「適正使用」の中身（いま何がまずく、誰が間違えているのか）が分からない。
- 「学生や新人が」と聞いた時点で「自分向けではない」と感じた。

## 3. 置いていかれた所・疑問に思った所
- 0:12.8〜0:19.8（シーン1）：肩書きカードが4行。等速でも読めず「すごい人っぽい」だけ残る。
- 0:36.1〜0:40.1（シーン2）：「グラム染色の見た目」。×4 の盤面のどこを見ればいいか分からない。そもそも、なぜ膀胱？
- 0:59.3〜1:07.7（シーン3）：表が細かく、赤い「28%」が何の数字か分からない。疑問：「ほとんどの菌に効く薬で全部倒したのに、なぜ耐性菌が増えるの？」理由が言われない。
- 1:09.0〜1:11.1（シーン4）：いきなり2050年。「同じ使い方を25年続けたら」という前提は画面の小さい字だけ。
- 1:28.6〜1:40.5（シーン5）：カタカナが約12秒に詰め込まれ、完全に脱落。続く ×25 の約4秒は声がなく、何を見るか分からない。
- 1:45.0〜1:48.4（シーン5）：「今度は守り切れました」。1回目と何が違ったか、数字の比べがない。コマでは、負けの「膀胱が破られた」ほど目立つ勝ちの画面が見えなかった。
- 2:01.5〜2:07.1（シーン6）：「乱用でも守れてしまう回が多ければ」。一瞬「守れるならいいじゃん」と思い、教材にならないからだと気づくのに数秒かかった。
- 2:07.2〜2:12.9（シーン6）：Claude に数値を作らせない理由が言われない。「自分の地域のデータ」が大事な理由も分からない。「ゆっくり ×2」は遅いのか2倍速なのか迷った。

## 4. いちばん心に残ったこと
（けんた）「楽勝だった戦い方のせいで、25年後の自分が負ける。『あなたの選択が、未来の敵をつくる』で鳥肌。ミクロ経済で習った外部性や『共有地の悲劇』と同じ形じゃん。目先は得なのに、ツケが未来に回る。」

整理：シーン3→4の「勝ったのに、あとで負ける」は、医療を知らなくても体で分かる。この動画のいちばんの武器。

## 5. そもそも説明が足りないと思うこと
1. **抗菌薬＝いわゆる抗生物質、の一言**。ないと自分の体験とつながらない。
2. **耐性菌が増える理由**。止めて見ると、タイトル画面の小さい字に「使った薬にさらされた菌の中で、その薬に耐性の菌が残って増える」とあった。これが声で言われていれば、シーン3も「選択圧」もつながった。
3. **「ほとんどの菌に効く薬」と「その菌に効く薬」の違い**。ないとシーン5で何を変えたか分からない。
4. **誰が薬を選ぶのか**。患者の自分は関係あるのか。風邪でもらった抗生物質は「乱用」だったの？
5. **なぜ膀胱か、1,000万人は世界の数字か**。

## 6. 後半の「教える側」は分かったか、すごさは伝わったか
分かったのは「先生が条件を入れると、AI がステージを作り、何回もテストプレイして、簡単すぎたら難しくする。最後は専門家がチェックして配る」まで。右の工程の図と右下の「27% → 17%」のおかげで追えた。「AI が自分で遊んで、自分で直す」はすごいと感じた。
ただ、伝わったすごさは半分。27% の意味、地域のデータを使う意味、数値を作らせない理由（AI のでっち上げ防止？）が言葉になっておらず、「なんとなくすごそう」で止まる。シーン7は自分には関係ない話に聞こえた。

## 7. 遊んでみたいか・人に勧めたいか
中くらい。2050年に負ける仕掛けとドット絵はいい。でも英字のカードが8枚並ぶのを見て「自分には無理そう」と思った。勧めるなら薬学部の友達。経済学部の友達には「共有地の悲劇のゲーム」として話のネタにする。

## 8. こうすれば伝わる（優先順）
1. **「抗菌薬（いわゆる抗生物質）」と最初に一度だけ併記する**。これで「自分も飲んだ薬の話」になる。
2. **シーン3の「ところが」の前に、耐性菌が増える理由を一文で言う**。タイトル画面の説明を声にする。シーン4の「選択圧」がここで回収される。
3. **シーン5は薬の名前を声から外し、考え方だけを言う**。例「菌が分かったら、何にでも効く薬から、その菌に効く薬へ。最強の薬は取っておく」。薬名はテロップへ。最後に1回目と2回目の結果（耐性率・勝ち負け）を左右に並べる。
4. **シーン2は見る場所を一つにする**。「グラム染色」は「顕微鏡で見た形」などに言いかえ、菌を1匹だけ丸で囲み、遠く→近くで表示が変わるのを等倍で見せる。なぜ膀胱かも一言。
5. **シーン6に「なぜ」を足す**。「地域ごとに効く薬の割合が違う」「乱用で勝てるステージは教材にならない」「AI に数値を作らせると間違えるおそれがある」。シーン1の肩書きは2行に減らす。
