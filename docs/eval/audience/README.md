## 全員に共通した指摘（重い順。人数は、各報告の中の言葉から数えた目安）

1. **「薬を使うと、効く菌は死に、効かない菌だけが残って増える」という仕組みが、声でも絵でも一度も語られない**（10人全員）。題名の「選択圧」もこれ。中学生と外国出身の人は「耐性＝人の体が薬に慣れること」と思い込んだまま進んだ。タイトル画面の小さい字には書いてあるが、動画では読めない
2. **「ほとんどの菌に効く切り札の薬」と「その菌に合う薬」がある、という区別がない**（8人）。だからシーン3（切り札の連打）とシーン5（合う薬へ切り替え）が対にならない。「メロペネム＝カルバペネム系」とも言っていないので、同じ薬か別の薬か分からない（7人）
3. **なぜ切り札が選ばれやすいのか（最初は原因の菌が分からず、検査の結果が出るまで時間がかかる）がない**（IT エンジニア・保護者・元教員ほか）。「遠くでは見た目だけ、近づくと名前と効く薬が分かる」が、現実の検査の時間差の比喩だと伝わらない

## 伝えるための「前提の鎖」（3分の制限を外した、すべての人向けの順番）

1. 細菌は、体に入ると病気を起こす小さな生き物。膀胱炎も細菌が原因（かぜの多くはウイルスで、別のもの）
2. 抗菌薬（いわゆる抗生物質）は、細菌を倒す薬。ウイルスには効かない
3. 薬ごとに、効く細菌の範囲が違う。狙いをしぼった薬と、ほとんどの細菌に効く「切り札」（例：メロペネム＝カルバペネム系）がある
4. 最初は原因の細菌が分からない（検査の結果が出るまで数日）。外して悪くなるのが怖いので、切り札が選ばれやすい。効けば、そのまま使い続けがち
5. 薬を使うと、効く細菌は倒れ、たまたま効かない細菌だけが生き残って増える。変わるのは人の体ではなく、細菌のほう。切り札ほど、多くの種類の細菌にこの「ふるい」をかける＝選択圧（せんたくあつ）。ゲームの名前
6. 効かない細菌が増えると、いざというとき効く薬がなくなる → 2050年の試算
7. 適正使用：検査で細菌と効く薬が分かったら、その細菌に合う薬に切り替える。切り札は本当に必要なときのために取っておく
8. 一般の人にできること：かぜに抗菌薬を求めない、出された薬は指示どおりに飲む、余った薬を自分の判断で飲まない・人にあげない（言い回しは公的な啓発資料で確かめてから使う）
