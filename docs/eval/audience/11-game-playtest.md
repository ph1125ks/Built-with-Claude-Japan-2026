## 伝わったこと／伝わらなかったこと

- **抗菌薬とは**：伝わらなかった。説明がどこにもない。「抗菌薬＝細菌をやっつける薬」の一文が、タイトルにも遊び方にもない。盤面の兵士が弾を撃って菌が減ることで、「薬で菌が倒れる」ことはなんとなく分かる。
- **効く菌が違う**：半分伝わった。盤面で「耐性：CEZ」「自然耐性：…」の札が出て、「効かない薬がある」ことは分かる。ただし、「この菌にはこの薬」という関係は、盤面では見えにくい。開始前に折りたたまれているアンチバイオグラムの表（菌×薬の感性率、色付き）が、これを一番よく見せているが、見ない人が多い。
- **広く効く薬が選ばれやすい理由**：伝わらなかった。カードの「大腸菌など／緑膿菌／腸球菌」のタグが緑なら効くことは分かるが、MEPM が幅広く効くことも、だから迷ったら選ばれやすいことも、ゲームの中の文では出てこない。「まず効く見込みの高い薬（多くは広い範囲に効く薬）で始め」という一文が遊び方にあるだけ。「なぜ広い薬を最初に選ぶのか（正体が分からない間は、外すと危ないから）」の理由がない。ゲームは「まず広く」を求めながら「広いと悪い」と教えるので、矛盾して見える。作者が心配しているとおり、説明しないと伝わらない。
- **耐性菌が残って増える**：少し伝わった。薬を使い続けたあとの帯（「緑膿菌の MEPM 耐性 12%→14%」）と、結果の表の赤い数字で、「使った薬の耐性率が上がる」ことは見える。しかし「効く菌が死に、効かない菌が生き残って増える」という仕組みは、絵で見えない。「選択圧」の言葉は分からない。MEPM を連打したステージ1では、大腸菌の MEPM 耐性が 0.1→0.8% と小さく、ふみこには「ほとんど変わらない」としか見えない（緑膿菌だけ 12→28%）。
- **2050年に負ける理由**：結果画面だけでは伝わりにくい。まとめの振り返り（「広く効く薬ばかり使うと…効かない菌が増えます」）を読めば分かる。結果画面に「系統 100%」とあるだけで、「自分のせい」とは書いていない。ステージ1も「守り切った」と出るため、広い薬の連打が悪いのかどうか、2050年に着くまで分からない。
- **適正使用とは**：伝わらなかった。「菌の正体が分かったら狭い薬に切り替える」は遊び方に文章であるだけ。適正に遊ぶ自動操作（demo-proper）でも、使った系統の68%が第3世代セフェムで、Access 薬（ABPC）はほとんど使わず、ステージ1でも CTRX の耐性が 32%→73% に上がった。それでも2050年を「守り切った」ため、「適正＝狭い薬を使う」の絵にならない（デモの動きと説明が合っていない）。勝ち負けが運と薬の組み合わせで決まって見え、「どうすれば適正か」が見えない。

## ゲームの中に足すとよい説明（優先順）

1. **タイトルの直下に、30字ほどの「ルールの一文」**。「抗菌薬＝細菌をやっつける薬。細菌ごとに効く薬が違い、使うほど『効かない菌』が残って増えます。」（耐性菌の言い換えは「薬が効かない菌」）。「耐性＝薬が効かないこと」も同じ画面で。
2. **遊び方を「3枚のカード・1画面1つ」に分け、最初に絵で見せる**。1枚目は「菌が来る→薬で倒す」、2枚目は「菌ごとに効く薬が違う（アンチバイオグラムの小さな表を、色だけで）」、3枚目は「使うほど、効かない菌が残る（菌のイラストが、倒れる菌と生き残る菌に分かれる絵）」。いまの4列の文章は、「くわしく」に折りたたむ。
3. **「広く効く薬はなぜ選ばれる？」を、MEPM カードまたはステージ1の開始前に一言**。「菌の正体が分かる前は、外すと危ないので、広く効く薬が選ばれやすい。でも広い薬ほど、たくさんの菌に『効かない菌を残す力』がかかる」。さらに、ステージ1の MEPM の最初の1回目に、吹き出しで同じことを出す。
4. **結果画面（特に負けたとき）に、いちばん上に1行の原因を出す**。「あなたはカルバペネム系を100%使いました。そのため、2050年には手札の薬が効かない菌が12%になり、膀胱が破られました」。数字（AHI など）は「くわしく」に折りたたみ、各数字に「良い／悪い」の矢印と目安を付ける（例：AHI は 0 に近いほど偏り、1 に近いほど分散）。
5. **ステージ1の結果で、「広い薬だけで守り切った」ときに警告を出す**。「勝ちましたが、広い薬ばかり使いました。2050年に影響します」と。連打が正解に見える問題の対策になる。
6. **盤面の札の文字を大きくして、重ならないように位置を固定する**。「自然耐性」は「この菌にはもともと効かない」、「耐性：」は「この個体は効かない」と、札に1行で添える（または初回だけ吹き出し）。膀胱の真上に出る札は、右へずらす。ステージ2の下の帯は、右端で切れないよう折り返すか、短くする。
7. **カードを、一般名を主、略号を従にして表示し、Access と Watch に一言**。たとえば Access に「まず使う薬」、Watch に「使いすぎ注意」の札。吸収率と投与間隔は、「飲み薬：体に届くのは98%」「待ち 24秒（1日1回の薬）」と文章にする。
8. **「選択圧」という言葉を、帯ではなく絵と平仮名で言い直す**。「波が片付いた：薬が効く菌は減り、効かない菌が残った。緑膿菌の MEPM が効かない割合 12%→14%」。帯の表示時間を長くするか、記録（ログ）として残す。

## そのほかの気づき

- 幅1280・768とも、画面の崩れ（はみ出し・重なり）は、盤面の札とステージ2の帯以外では見つからなかった。「幅1024px以上をおすすめ」の帯が、幅800付近で出る。
- 数字キーでカードを選べると書いてあるが、遊んでいる最中は反応しなかった（試した範囲では、クリックだけが有効）。
- 「はじめる」を押すと、遊び方が先に出て、もう一度「はじめる」を押す流れ。初めての人には親切だが、2回目以降は不要。
- 注意書き（教育用・誇張・薬価）は、タイトルとまとめにあり、見える。医療アドバイスに見える言い回しは見つからなかった。
