# 評価の記録

作ったものが「伝わるか」「効いているか」を、作者の感覚だけで決めないために行った3つの評価。評価役はどれも Claude のサブエージェントに人物を演じさせたもので、実在の人ではない（人物が知っていることだけで判断するように指示した）。

| フォルダ | 何を確かめたか | いつ | 結果の要点 |
|---|---|---|---|
| [audience/](audience/README.md) | デモ動画（台本 第2版）が、医療を知らない人を含むすべての人に伝わるか。中学生〜72歳、保護者、外国出身の人、審査員など10人の評価役と、ゲームの試遊1件 | 2026-11-05 | いちばん伝わったのは「自分が残した耐性菌に負ける」場面（10人全員）。伝わらなかったのは「やり直し」（7秒に薬の名前が4つ）→ 台本 第3版と [PLAIN-LANGUAGE.md](../PLAIN-LANGUAGE.md) に反映 |
| [story/](story/README.md) | 作者の物語を軸にした台本（第4版）が伝わるか・心に残るか（5人の評価役）。続けて第5版（[v5/](story/v5/README.md)）、第2〜6版の比べ直し（[versions/](story/versions/README.md)。初見の読み手3人に版を伏せて読ませた） | 2026-11-05〜06 | 第4版は「私ごとすぎる」（作者）、第6版は初見で最下位 → 第7版「ゲームを早く出す」へ |
| [skill/](skill/README.md) | スキル `stage-design` を教員モードの Claude に渡すと、ステージ設計が良くなるか。同じ入力で、スキルあり・なしを各3回（本物の `claude-opus-5-5`） | 2026-11-05 | スキルありは規則の誤りがなく、時間と費用が約3割少ない（件数が少ないので目安） |

評価の作り方（人物の設定、渡した資料、問いの立て方）は、それぞれのフォルダの `README.md` と `00-materials.md` にある。ゲームの試遊（サブエージェント `playtester` がアプリ内ブラウザで実際に遊ぶ）は4回行い、記録の例は [audience/11-game-playtest.md](audience/11-game-playtest.md)、直したことは [../DEVLOG.md](../DEVLOG.md) の「試遊」の節にある。
