- `scripts/make-bgm.ts`（サブエージェントが作成）：矩形波・三角波・ノイズだけで合成するファミコン風の曲（BPM 120、ニ短調／ヘ長調）。区間の気分は hook（不穏）・play（明るい）・tension（2050年、短調で刻む）・hope（やり直し、長調）・build（教える側と作り方、落ち着いた分散和音）・outro（ヘ長調で解決）。画面が大きく変わるところにシンバル風の音。-18 LUFS、ピーク -1.5 dBFS で書き出し、同じ cue からは毎回同じ音になる
- 重ね方（`make-draft-video.ts`）：声を -16 LUFS にそろえ、BGM を -10 dB して声の下に置き、声の間はサイドチェーンでさらに下げる（`BGM_DB`）
- **Claude は音を聞けない**。数値とスペクトルの画像だけで確かめた。作者が聞いて、大きさ・くり返し感・不穏さを確かめる（気になれば `BGM_DB` や `make-bgm.ts` の区間を直す）

## 5. 開発の仕組みと、つまずきやすい点

- **教員モードの Claude**（`server/agent.ts`）：Claude に「考えを文で書いて画面に流して」と頼むと、考えの過程を抜き出す依頼（`reasoning_extraction`）とみなされて断られる。作業の経過は `thinking.display: "updates"`（beta `thinking-display-updates-2026-08-18`）で受け取る。断られたときは、分類と説明をサーバーの記録に出す。データの数値の出どころ（入院検体のすべての検査材料・菌全体の値）は、ツールの説明とスキル `stage-design` に書いてある
- **コミット前のフック**（`.claude/hooks/check-secrets.sh`）：コマンドの文字列そのものと、コミットされうるファイルの両方を調べる。`git commit` を含むコマンドに、キーの形の文字列（見本でも）を書くと止まる。コミットのメッセージやヒアドキュメントに見本のキーを書かない
- **録画中はゲームのコードを編集しない**（開発サーバーが画面を読み直して録画が乱れる）。`index.html` や `public/`（favicon・og-image）に触れても読み直すので、録画の前か後に。録画はこのセッションの開発サーバー（`.claude/launch.json` の "game"。5173 が使われていると 5174 になる）に `--base` で向ける。教員モードのサーバーは、コードを直したら止めて動かし直す（自動では読み直さない）
- **教員モードのサーバーが出す「手元で遊ぶ」の URL** はポート 5173 のつもりで作る（`LOCAL_BASE`）。開発サーバーが別の番号のときは、その URL は開かない

- **公開**：main に push すると `.github/workflows/pages.yml` が動く（`npm ci` → `npm test` → `npm run build` → Pages）。`data/raw/` はリポジトリにないので、CI では `data:verify` を動かさない。公開と同じサブパス（/Built-with-Claude-Japan-2026/）で確かめるときは、`npm run build` のあと `.claude/launch.json` の "pages-preview"（ポート 4173）。Actions の結果は `gh run list --workflow pages.yml` で見られる
- **GitHub 側の状態を話す前に** `git fetch` と `git status -sb` で、push 済みかどうかを確かめる
- **GitHub の保護機能**（2026-11-07、作者の判断で API から有効にした）：secret scanning・push protection・Dependabot security updates。キーの形の文字列を push すると GitHub 側でも止まる。Dependabot の PR が来たら、提出前は様子見でよい（公開ビルドに入るのは phaser と @fontsource だけ。`exceljs` 経由の `uuid` の moderate はデータ取り込みのスクリプトだけで使う）
- **公開サイトの安全**（2026-11-07）：URL の値（`?stage=`・`?region=`）は誤りの文に入ることがあるので、`src/game/main.ts` の読み込み失敗の画面は `escapeHtml` で描く。`readParams` は地域名を 20字以内・記号なしに限る。新しく URL の値を画面に出すときは、`textContent` か `escapeHtml` を通す
- **教員モードのサーバーの受け付け**（`server/teacher.ts`、2026-11-07）：Host が loopback 以外・Origin が手元以外・POST が JSON 以外は断る。開発サーバーの proxy を通る要求は Host が localhost:5173 で届くので、ポートは見ない。API キーの見本は `.env.example`（値なし）
- **シーン8 の作り**（2026-11-08）：教員モードの録画 `recordings/teacher.mp4`（本物の Claude の回）を4段に切る。作業の記録の中の区切りは `make-draft-video.ts` の `RUN8`（dataEnd・planEnd・judgeEnd、録画の秒）で、録画を撮り直したらコマを見て直す。撮り直しは `npm run teacher`（API キーはサーバーが読む。料金がかかるので作者の了承を得てから）と開発サーバーを動かし `npx tsx scripts/record-demo.ts --take teacher --base http://localhost:5173`。承認で `public/stages/<id>.json` が書かれる（同じ id なら上書き）

- **英語の字幕**（2026-11-08）：DEMO.md の各シーンの「**英語字幕**」の行（ナレーションの区切り＝字幕と同じ数）から `recordings/draft-video.en.srt` を同じ時刻で出す。行数が違うと警告して1つにまとめる。画面の字の英訳3つ（シーン0・6・エンドカード）は `make-draft-video.ts` の `EN_EXTRA`。ナレーションの文を変えたら英訳の行も直す

- **動画のシーン3の作者の映像**（`scripts/make-draft-video.ts`、2026-11-07）：`recordings/author/self.mp4` があれば、`selfVoice`（映像の音。頭の無音を測って切る）と `selfClip`（`introVideo` の絵の左の 704×396 の枠に映像を重ねる。枠の位置は Chrome で測る。枠は縦横とも偶数にする：奇数だと yuv420p の縮小で `pad` が失敗する）を使う。`--self <file>` で別の映像、`--self none` で写真に戻す。`--out <name>` で `recordings/<name>.mp4` に試し書きできる（絵コンテ表のスクリプトは `draft-video.json` を読むので、本番は `--out` を省く）

  - 編集後：`src/engine/`・`tests/`・`data/` を編集すると単体テストが走る。複数の編集の途中でも失敗を知らせてくるので、最後まで編集してから判断する（`src/game/` は対象外。`npm run typecheck` と `npm run build` で確かめる）

- **医学資料の置き場所**：追加フォルダ（Cowork）の `04_医学資料`（索引は `00_README.md`）。ASC スコアの論文は `08_ASCスコア/`、NAOR 2024 は `07_NAOR2024/`。本文はリポジトリにコピー・引用しない。作者が新しい資料を `_inbox/` に置いたら、読んでから番号付きのフォルダに日付付きの名前で移す
- **録画と仮の動画**：録画は開発サーバーを動かしてから `npx tsx scripts/record-demo.ts --take title,abuse,proper --base http://localhost:5173`（画面なしの Chrome。1本5〜7分かかるので裏で動かす）。仮の動画は `npx tsx scripts/make-draft-video.ts`（約3分。作者の写真 `recordings/author/photo1.jpg` が要る。声は `recordings/voice/` の録音か、なければ `say -v Kyoko` の仮の声）。絵コンテ表は `npx tsx scripts/make-storyboard.ts`。どちらも `recordings/` に書き出す（Git に入れない）。台本の文は DEMO.md から読むので、直したら書き出し直すだけでよい。耐性モデルや医療費・ステージを変えたら、`npx tsx scripts/demo-seeds.ts` で種を確かめる（`tests/demo.test.ts` が落ちたら選び直す）。手元の ffmpeg には文字を描く機能がないので、字幕は Chrome で描いて重ねている
- **兵士と細菌の絵**（`src/game/pixel/`）：コードで書いたドット絵。`engine.js` が仕組み（行の文字列 → ドット、色の段、輪郭、点描、切り抜き）、`styles/c32.js` が作風 C（9系統の兵士の待機2コマ・攻撃2コマ、細菌5種の2コマ、べん毛のない絵 `bare`）。どちらも JS で、型は横の `.d.ts`。盤面では `BoardScene.makeTextures` で、薬×コマ×濃さ8段と、菌×2コマ×べん毛の有無を等倍のテクスチャにし、ぼかさずに拡大する（NEAREST）。カードと遊び方の絵は `soldierImg` で整数倍の PNG にして `<img class="px">` で出す（カードは上半身の切り抜き `cardCrop`）。系統を足したら、`soldiers.ts` の `CLASS_LOOKS` と作風の絵の両方に足す（`tests/pixel.test.ts` が全部の薬のコマ・紋章・台・べん毛なしの絵を確かめる）。レーンの兵士の絵は菌より下の層（深さ 8）、名札だけ菌の札より上の層（深さ 30）。ほかの4作風と見本帳の元ファイルは、リポジトリの外（作者の手元）に控えてある
- **画面の見た目**（15回目）：色は `src/game/theme.ts`（盤面）と `style.css` の `:root`（DOM）。アイコン・膀胱・弾・粘膜の帯・床の模様は `src/game/pixel/icons.ts`（DOM には `iconImg`）。盤面の文字（canvas）は、あとからフォントが届いても描き直されないので、`main.ts` の `loadBoardFont` で先に読み込む。**盤面に新しい漢字の文を足したら、その文字を `loadBoardFont` の一覧にも足す**（足さないと端末のフォントで描かれる）。ドット絵のフォント（DotGothic16）は 16px 以上だけに使う
- **タイトルのデモ画面**：`app.ts` の `startAttract` が、タイトルと遊び方の後ろで適正ボットに遊ばせる（2倍速、終わったら次の回）。`window.sentakuatsu.current` は "title" のまま。`fastForward` は遊んでいるステージにだけ効く
- **「3・2・1」で始まるステージ**：手で遊ぶすべてのステージ（やり直しも）。`?auto=` のときは数えない（録画とタイトルのデモはそのまま）。途中で「一時停止」「？」「アンチバイオグラム」を押すか、スマホを縦向きにすると数えるのをやめて止まる
- **撮影の確かめ方**：画面なしの Chrome で各画面を撮るスクリプトを、スクラッチパッドに置いて使った（`scripts/lib/chrome.ts` の `openChrome` と `page.png()`、マウスは `Input.dispatchMouseEvent`）。録画と同じ 1920×1080・`?r=1.5` で 60fps 出ることを確かめた
- **バージョン**：Phaser は 3.90.0 に固定。TypeScript 7.0、Vite 8、Vitest 5。本番ビルドは約 1.4MB（Phaser が大半）。フォントは `@fontsource/dotgothic16` 5.3.1（文字の範囲ごとに分かれていて、使う文字の分だけ読み込まれる）
- **EUCAST のサイト**はスクリプトからの直接ダウンロードを 403 で拒否する。回避はしない
- **日本語を含む一括置換**：シェルのヒアドキュメントに Python を書くと、日本語が化けて失敗したことがある。スクラッチパッドに `.py` を書いて実行するほうが安全。`json.dumps` で JSON を書き直すと整形が全部変わるので、行を差し替える。JSON を行で書き換えたら、カンマの抜けや重なりに気をつける（テストが全部落ちる）
- **データを足したら** `npm run data:build` で `data/generated/` を作り直す（薬価がないとテストが落ちる）。手順はスキル `janis-import`
- **数値の集計**：`npm run sim` は平均。DEVLOG の耐性率の表は中央値。表に書くときはどちらかを明記する。データを変えると、値を直接確かめているテスト（ASC、ボットの選ぶ薬、供給制限の枚数など）も直す
- **シミュレーションの補助**：`runScenario`（`src/engine/simulate.ts`）の戻り値に、ステージ1の始めと終わりの耐性率（`present.resistanceStart`・`resistanceEnd`）と、2050年の開始時の表（`futureStart`）がある。`npx tsx` でスクリプトから呼べる。ルールを書き換えずに試すときは `loadGameData({ rules: { board: { ...base.rules.board, revealSusceptibilityBelow: 0.6667 } } })` のように上書きする（上書きは最上位の項目ごと）
- **引き継ぎの呼び方**：`model.carryOver(data, start, end, years, usedDrugsOf(present.activeDays))`。最後の引数を渡さないと、使わなかった薬を下げない
- **代用の組をつなぐ設定**（`resistance.A.sharedSelection`）は、`susceptibility.proxies` の useJanis の組と一致しないと、読み込みのときに止まる（`src/engine/data.ts`）
