## 3. 決まっていて変えないこと

- **作者の方針**：医学的な値は、できるだけ作者の感覚ではなく公的な文書に沿って決める。文書で決まらないものは作者に聞く（選択肢と根拠を示して）。値を変えたら出典（文書名・版・ページ）を書く
- **耐性化の速さ**（2026-11-03、作者の方針）：公的資料から採ったと言えるようにする。極端にしない（臨床では感性率 80% 未満でエンピリックに使いにくく、耐性率 50% でも大問題）。2050年までの上がり方は NAOR 2024 の実測の最速を上限。RAND の「15年で100%」は使わない
- **使わない薬の耐性**（2026-11-03、作者の判断）：下げるのは2050年への引き継ぎだけ。ステージ1の中では下げない。NAOR 2024 の実測の下がり方が上限
- **系統の偏りの倍率**（2026-11-03、作者の判断）：考え方は AHI、式と係数はゲームの決めごと。文献の確認や作者の研究の式には合わせない（結果画面の「偏りの指標」の式とは別）
- **言葉**（2026-11-03、作者の方針）：ゲームなので、画面・台本で「患者・病棟」の語を使わない（倫理的な配慮）。未来ステージは「2050年」と呼ぶ
- **偏り**：必要なところにバランスよく使うことを大切にする。最適な薬を選んでいれば系統がそろう、が理想（いまは届いていない）
- **ゲームの中の Claude** は教員モードでステージを作る役だけ。学生と会話する機能は作らない
- **用法**：手引きの治療例の表に合わせる。AMK だけ JAID/JSC 2023 Ⅺ-E。**カードには用量を出さない**（投与間隔と待ち時間だけ）
- **優先して使う順**：WHO の AWaRe（Access → Watch → Reserve）。同じ群ではカルバペネム系とキノロン系を後に回す。同順位はカバー率の低いほう
- **連動**：ESBL（CTRX → ABPC・CEZ・経口第3世代セフェム・CFPM）と CRE（MEPM → CTRX・CMZ・TAZ/PIPC。CRE は作者の確認待ち）。菌ごとの木にして、全体の耐性率は表の値を保つ。耐性モデルで値を変えたら必ず下限をかけ直す（エンジンの `withModel` と `extrapolate` がやる）
- **効く確率**は JANIS の S のみ。自然耐性は EUCAST Expected Resistant Phenotypes v1.2。腸球菌の MEPM は「効かない扱い」と表示する（自然耐性でも獲得耐性でもない）
- **台本**：シーン3の「MEPM を連打して楽勝」は、ボットではなく録画用の操作シナリオで作る。シーン0の字幕は「抗菌薬が、効かなくなる。」

## 5. 開発の仕組みと、つまずきやすい点

- **フック**（`.claude/settings.json`）
  - コミット前：`git commit` を含むコマンドで、API キーなどの文字列を探して止める
  - 編集後：`src/engine/`・`tests/`・`data/` を編集すると単体テストが走る。複数の編集の途中でも失敗を知らせてくるので、最後まで編集してから判断する（`src/game/` は対象外。`npm run typecheck` と `npm run build` で確かめる）
- **サブエージェント**：`data-auditor`（データや出典、画面の医学的な言い回しを変えたら）、`balance-tester`（シミュレーションの比較）、`playtester`（アプリ内ブラウザでの試遊）
- **サブエージェントを並べて動かすとき**：`balance-tester` と `playtester` はエンジンと画面をそのまま使う。動いている間に `src/` や `data/rules.json` を書き換えると、比較の数値が混ざったり、画面が再読み込みされたりする。変更はリポジトリの写し（スクラッチパッドに rsync、`node_modules` はリンク）で確かめ、終わってから本体に入れた
- **アプリ内ブラウザの画面が隠れていると、ゲームの時計がほぼ止まる**（描画のたびに進めているため）。確かめるときは、コンソールで `window.sentakuatsu.fastForward(秒)`、`window.sentakuatsu.press("start")` などを使う。`?auto=appropriate`（適正ボット）・`?auto=broad`（乱用ボット）で自動で遊ばせられる。スクリーンショットは1枚遅れて写ることがあるので、2回撮る
- **最初のステージは止めた状態で始まる**（`?auto=` のときを除く）。手で確かめるときは「再開」かスペースを押す
- **画面の URL**：`?stage=`・`?model=A|B|none`・`?cost=yakka|abstract`・`?budget=はじめ,1日ごと[,上限]`・`?seed=`・`?region=`・`?auto=`・`?r=`（盤面の解像度。1080p の録画は `?r=1.5`）・`?debug`（耐性モデルの名前などの開発用の表示。`?model=` を付けたときも出る）
- **開発サーバー**：`.claude/launch.json` の "game"（ポート 5173。使われていると 5174 になる）
- **医学資料の置き場所**：追加フォルダ（Cowork）の `04_医学資料`（索引は `00_README.md`）。本文はリポジトリにコピー・引用しない
- **バージョン**：Phaser は 3.90.0 に固定。TypeScript 7.0、Vite 8、Vitest 5。本番ビルドは約 1.3MB（Phaser が大半）
- **EUCAST のサイト**はスクリプトからの直接ダウンロードを 403 で拒否する。回避はしない
- **日本語を含む一括置換**：シェルのヒアドキュメントに Python を書くと、日本語が化けて失敗したことがある。スクラッチパッドに `.py` を書いて実行するほうが安全。`json.dumps` で JSON を書き直すと整形が全部変わるので、行を差し替える
- **数値の集計**：`npm run sim` は平均。DEVLOG の耐性率の表は中央値。表に書くときはどちらかを明記する
- **シミュレーションの補助**：`runScenario`（`src/engine/simulate.ts`）の戻り値に、ステージ1の始めと終わりの耐性率（`present.resistanceStart`・`resistanceEnd`）と2050年の開始時の表（`futureStart`）がある。`npx tsx` でスクリプトから呼べる。ルールを書き換えずに試すときは `loadGameData({ rules: { board: { ...base.rules.board, revealSusceptibilityBelow: 0.6667 } } })` のように上書きする（上書きは最上位の項目ごと）
- **引き継ぎの呼び方**：`model.carryOver(data, start, end, years, usedDrugsOf(present.activeDays))`。最後の引数を渡さないと、使わなかった薬を下げない
