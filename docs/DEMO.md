## この動画で伝えること

1. **どれくらい困っているか**：抗菌薬が効かない、それが耐性菌の感染症（冒頭のテロップ）。このまま薬剤耐性が広がると、2050年には年間1,000万人が亡くなる。がんを超える、という試算がある
2. **抗菌薬を正しく使うことが大切。でも、学ぶ機会が少ない**：間違った使い方でも、いまはよくなる。影響が返ってくるのは何年も先で、実感しづらい。選んだ抗菌薬の影響を確かめながら学ぶ機会は、多くない
3. **どう解決するか**：何年も先の結果を数分で、安全に失敗しながら学べるタワーディフェンス
4. **作ったのは誰か（身元の開示）**：博士号と感染症の専門資格を持ち、病院で10年以上、感染症の治療に携わってきた薬剤師。経歴のカードに、名前・所属・論文・招待講演・学会の賞
5. **しくみ（すべての人に）**：抗菌薬（いわゆる抗生物質）は細菌を倒す薬。薬ごとに効く細菌が違い、ほとんどの細菌に効く「切り札」もある。なら切り札だけ使えばいい？ でも薬を使うと、効かない細菌だけが残って増える（選択圧。作者の研究テーマで、ゲームの名前）。切り札に甘えていると、切り札さえ効かない細菌が増える
6. **Claude の役割**：教える人が地域と教えたいことを入れると、Claude がその地域の公開データでステージを作り、自分で試して直す。数値は作らせない。膀胱炎のほか、肺炎など別の感染症にも広げられる。開発も Claude Code と一緒に行い、薬の値や耐性の速さは、作者が公的な文書と照らして確かめた
7. **これから**：これから現場に立つ人たちに届ける。いまの一手が、未来をつくる

- 画面に出る数値は、収録した版のデータのとおりにする。ナレーションに入れる数値は、2050年の試算と作者の「10年以上」だけ

## 動画の作り方

- **第一案（自動化）**
  1. ブラウザの自動操作でプレイ画面と教員画面を録画する（Claude が用意する）
  2. 作者がこの台本を読み、シーンごとに録音する
  3. スクリプトで録画・字幕・音声をつなぎ、MP4（1920×1080）に書き出す
  4. 作者が確認し、YouTube に限定公開でアップロードして、提出フォームに貼る
- **仮の動画**：`npx tsx scripts/make-draft-video.ts` で、録画（`recordings/`）を台本の時間配分どおりに切り出して早送りし、ナレーションを字幕と声にしてつなぐ。字幕と、コードで描く絵（時間のずれの図・名乗りの場面）は画面なしの Chrome で描いて重ねる（手元の ffmpeg には文字を描く機能がない）。台本のナレーション・字幕・作者紹介・使っていく場面は、この DEMO.md から読む（直したら書き出し直すだけでよい）。ナレーションの字幕は `recordings/draft-video.srt` にも出る（録音と YouTube の字幕の下書き）
  - **声**：`recordings/voice/scene1.m4a`（シーンの番号ごと。wav・aiff・mp3 も可）を置くと作者の録音を使う。ないシーンは macOS の読み上げ（`say -v Kyoko -r 200`。第6版から、作者の早口に合わせて1秒に約5.8字）で仮の声を作る。仮の声は尺を確かめるためのもので、提出版には使わない。仮の声のときは字幕の時刻を声の区切りに合わせ、画面の切り替わりに合わせたい文（`scripts/lib/video-cues.ts` の `ANCHORS`）はその時刻まで待たせる。録音のときは、頭と終わりの無音を切り、声の中の無音を手がかりに字幕の時刻を合わせる（`scripts/lib/align.ts`）。声の大きさは書き出しのときにそろえる（-16 LUFS）。声がシーンの枠からはみ出しそうなときは、書き出しの最後に警告が出る
  - **録音用の原稿**：`npx tsx scripts/make-recording-sheet.ts` で `recordings/recording-sheet/` に作る。シーンごとに枠の秒数・読み終える上限・字数・ファイル名・画面に合わせてあける「間」・読み方を並べる。作者には Artifact で見せる
  - **絵コンテ表**：続けて `npx tsx scripts/make-storyboard.ts` を動かすと、`recordings/storyboard/` に絵コンテ表（シーンごとの時刻・サムネイル・画面・テロップ・ナレーションと声の余り、縮小版の動画）ができる。作者には Artifact（非公開のページ）で見せ、直しを「シーン3」「0:52 の字幕」のように時刻かシーン番号で受け取る（Discord のオフィスアワーの助言）
  - **動く画面を主役に**（2026-11-05 作者の判断。オフィスアワーの助言）：名乗りの場面（シーン3の後半）と図（シーン1・2・9）のほかは、作品が実際に動く画面にする
- **代替案**：時間や API クレジットが足りないときは、PowerPoint にスクリーンショットと録画を貼り、音声付きで動画に書き出す
- 録画と合成は手元のツールで行うので、API クレジットはほとんど使わない。クレジットを使ったのは、シーン8の収録で Claude を動かした分だけ

## 収録前に作者が確かめること

- 読む速さ：第6版は1秒に約5.8字（第2版の録音の1割増し）で計算している。余りが小さいシーン（録音用の原稿に出る）は、間をあけすぎない
- シーン0のテロップ「抗菌薬が効かない。それが、耐性菌感染症。」と、上の小さな「楽勝だったはずなのに。」
- シーン2の「でも、間違った使い方でも、いまはよくなる。影響が返るのは、何年も先。だから、実感しづらい。」：作者の案「仮に正しくない使い方をしても、その影響は何年もかけて返ってくるから実感しづらい」を、図の段階（いま → 何年も先）に合わせて3つに切った文
- シーン3の順（ゲームにしました → 作ったのは）と、経歴のカード（4行）。声の「博士号と感染症の専門資格」は、カードの「博士（薬学）」「感染制御専門薬剤師」のこと。「10年以上」は薬剤師になってからの年数（2016年〜）。名前は声では言わない
- シーン4の「なら、切り札だけ使えばいい？」「切り札に甘えていると、切り札さえ効かない細菌が増えてしまう。」と、「はじめは原因の細菌が分からない」を声から外したこと。「私の研究テーマで、ゲームの名前です」：研究テーマの言い方（抗菌薬の選択圧と耐性の関係）
- シーン7の詰めた言い方（「切り札の連打より、確かに大変です」「守り切れました」）と、並べ比べを 3.6秒にしたこと
- シーン8で「切り札だけで守れてしまうなら、敵を強めて確かめ直す。」を声から外したこと（等倍の場面と上の一行で見せる）。「膀胱炎のほか、肺炎など別の感染症にも広げられます」が、いまのゲーム（膀胱炎だけ）に対して言い過ぎでないか
- シーン9の「すべて公的な文書で、私が確かめました」：作者の方針の言葉（医学的な値は公的な文書に沿って決める）に合わせた。EUCAST・ASC スコアの論文など、国の文書でないものも含むため「国の文書」とは言わない
