## この動画で伝えること

1. **誰の、どんな課題か**：薬学生や新人の医療者には、抗菌薬の適正使用を学ぶ機会が少ない
2. **どう解決するか**：選んだ抗菌薬が未来の耐性菌をつくることを、遊びながら体感できるタワーディフェンス
3. **Claude の役割**：教える人が地域の公開データと教えたいことを入れると、Claude がステージを設計する。シミュレーションで検証してから出す
4. **使い続ける場面**：病院実務実習、院内の新人研修、大学・専門学校の講義

## シーン別の台本

### シーン0　つかみ（0:00–0:04）

- **画面**：ステージ2で負ける瞬間（シーン4と同じ録画の一部）。紫やピンクの細菌が、抗菌薬の弾をはじきながら膀胱に入っていく。膀胱の耐久ゲージが0になる
- **字幕**：「どの抗菌薬も、効かない。」
- **ナレーション**：なし

### シーン1　課題・誰のためか・作者紹介（0:04–0:24）

- **画面**：タイトル画面「センタクアツ ― あなたの選択が、未来の敵をつくる」→ 作者紹介の字幕
- **字幕（作者紹介。6秒ほど出す）**
  - 沢田 佳祐｜薬剤師・博士（薬学）
  - 枚方公済病院 薬剤科（AST）／京都薬科大学 臨床薬剤疫学分野 研究員
  - 感染制御専門薬剤師・感染制御認定薬剤師・病院薬学認定薬剤師（日本病院薬剤師会）
  - 抗菌化学療法認定薬剤師（日本化学療法学会）／医療薬学専門薬剤師（日本医療薬学会）
- **ナレーション**（108字）
  > 薬剤耐性菌を増やさないために、最も大切なのは抗菌薬の適正使用です。でも学生や新人には、それを学ぶ機会がほとんどありません。そこで、AST 薬剤師として耐性菌と向き合ってきた私が、体験しながら学べるゲームを作りました。

### シーン2　遊び方（0:24–0:44）

- **画面**：ステージ1の開始。右（尿道側）から3本のレーンで細菌が進んでくる
  - 遠くの細菌は、グラム染色の色と形だけが見える（紫の球菌、ピンクの桿菌）
  - 中ほどまで来ると菌名が出る（例：「大腸菌」）
  - 膀胱の近くまで来ると、効かない薬のマークが出る（例：「CTRX 耐性」）
  - 下の手札から抗菌薬カードを選び、レーンに召喚する。右上の医療費が減る
- **字幕（補足）**：「遠く：グラム染色像 → 中ほど：菌名 → 近く：感受性」
- **ナレーション**（87字）
  > 守るのは膀胱です。右から細菌が攻めてきます。遠くではグラム染色の見た目しか分からず、近づくにつれて菌の名前、そして効く薬が分かってきます。手札の抗菌薬を選んで、迎え撃ちます。

### シーン3　ステージ1「いま」：広域薬を連打（0:44–1:06）

- **画面**：メロペネム（MEPM）を全レーンに連打する。細菌が次々に倒れ、勝利画面になる
  - 続けて結果画面を出す：系統別の使用割合（カルバペネム系が大半）、偏りの指標、菌ごとの耐性率の変化（矢印が上向き）
- **字幕（補足）**：「耐性化の速さは、ゲーム用に誇張しています」（結果画面の下に小さく）
- **ナレーション**（77字）
  > まずは、ほとんどの菌に効くメロペネムを連打してみます。……楽勝です。ところが結果を見ると、使った薬はカルバペネム系に偏り、生き残った耐性菌が増えています。

### シーン4　ステージ2「数年後の同じ病棟」：負ける（1:06–1:28）

- **画面**：「数年後の同じ病棟」の見出し → ステージ2の開始
  - ステージ1の結果を引き継いだ耐性菌が押し寄せる。近づくと、手札のどの薬にも「耐性」のマークが付いている
  - 召喚した抗菌薬の弾がはじかれ、膀胱が破られる → 敗北画面
  - 最後に大きく「あなたの選択が、未来の敵をつくる」
- **ナレーション**（96字）
  > ここから数年後の同じ病棟へ。押し寄せるのは、さっき自分が残した耐性菌です。手札のどの薬も効きません。あなたの選択が、未来の敵をつくる。このゲームの名前「センタクアツ」は、選択圧から取りました。

### シーン5　やり直し：適正に使う（1:28–1:52）

- **画面**：ステージ1を最初から。早送りでつなぐ
  - ピンクの桿菌に、まずセフトリアキソン（CTRX）を召喚する
  - 近づいて「CTRX 耐性」が見えた大腸菌のレーンに、セフメタゾール（CMZ）を召喚して倒す
  - 紫の連鎖球菌（腸球菌）にセフェム系の弾がはじかれ、「自然耐性」と出る → アンピシリン（ABPC）に切り替えて倒す
  - 内服の第3世代セフェムを召喚すると、HP が削れた状態で出てくる（字幕で「吸収率が低い」）
  - 1日4回の薬は召喚の待ち時間が短く、1日1回の薬は長い（字幕で「待ち時間＝投与間隔」）
  - ステージ2も守り切り、勝利画面
- **字幕（補足）**：「投与回数・吸収率は、厚生労働省『抗微生物薬適正使用の手引き 第四版』をもとに設定」
- **ナレーション**（118字）
  > やり直します。菌と感受性が分かったら、カルバペネムを温存できる薬に切り替えます。第3世代セフェムが効かない大腸菌にはセフメタゾール、腸球菌にはアンピシリン。投与回数や吸収率も、国の手引きをもとにしています。今度は数年後も守り切れました。

### シーン6　教える側：Claude がステージを作る（1:52–2:32）

- **画面**：教員用の画面（作者の手元で動かす）
  1. 地域を選ぶ（例：全国 → 大阪府）。選んだ地域の感受性率の表が出る
  2. 「教えたいこと」に入力する。例：「第3世代セフェムが効かない大腸菌に、カルバペネムを使わずに勝つ経験をさせたい」。対象は「病院実務実習の薬学生」
  3. 「ステージを作る」を押す。Claude の作業ログが流れる（待ち時間は早送りし、画面に「早送り」と出す）。ログの例：
     - 「大阪府の大腸菌は CTRX 耐性が◯%。この値はデータのまま使う」
     - 「案1：乱用ボットが未来ステージでも勝ってしまう → 手札の MEPM を1枚に減らし、CMZ を入れる」
     - 「案2：適正ボットの勝率◯%、乱用ボットは未来ステージで負ける → 合格」
  4. できたステージをプレビューで少し遊ぶ → 「承認して公開」→ 学生用の URL と QR コードが出る
- **字幕（補足）**：「感受性の数値は公開データ（JANIS）がもと。Claude には作らせない」「最後は専門家が確認して公開」
- **ナレーション**（186字）
  > ここからは教える側の画面です。地域の公開サーベイランスデータと、教えたいことを入力すると、Claude がステージを設計します。Claude は自分でシミュレーションを何度も回し、「乱用すると負け、適正に使えば勝てる」が成り立つまで、手札や敵の出し方を直します。感受性の数値は公開データから取り、Claude には作らせません。最後に専門家が確かめてから、学生に配ります。
- **注意**：ログの文言は例。実際に Claude を動かした回のログをそのまま映す

## 収録の準備

- ゲームは乱数の種（シード）を固定して収録する。同じ操作なら毎回同じ展開になるようにする（SPEC.md「完成の定義」）
- シーン3〜5のプレイは、録画用の操作シナリオ（乱用・適正）で自動再生する。手で遊ぶと尺がぶれるため
- シーン6だけは本物の Claude を動かして収録する。ログを作り物にしない
- 字幕は全編につける。ナレーションの文字起こしに加えて、用語の補足を出す（例：「選択圧」「自然耐性」）
- 画面に出る数値は、収録した版のデータのとおりにする。ナレーションに数値は入れない

## 動画の作り方

- **第一案（自動化）**
  1. ブラウザの自動操作でプレイ画面と教員画面を録画する（Claude が用意する）
  2. 作者がこの台本を読み、シーンごとに録音する
  3. スクリプトで録画・字幕・音声をつなぎ、MP4（1920×1080）に書き出す
  4. 作者が確認し、YouTube に限定公開でアップロードして、提出フォームに貼る
- **代替案**：時間や API クレジットが足りないときは、PowerPoint にスクリーンショットと録画を貼り、音声付きで動画に書き出す
- 録画と合成は手元のツールで行うので、API クレジットはほとんど使わない。クレジットを使うのは、シーン6の収録で Claude を動かす分だけ
