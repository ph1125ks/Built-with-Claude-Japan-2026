# 平易な言葉の決めごと（すべての人に伝わるように）

2026-11-05 作者の判断：医療を知らない人を含め、すべての人に伝わる内容にする（評価は [docs/eval/audience/](eval/audience/README.md)）。動画・ゲーム・「はじめての人へ」のページで、同じ言葉と同じ順番を使う。**医学的な言い回しは作者が確かめる**（【作者確認】の印）。

方針：

- **声（ナレーション）は平易な言葉、専門用語は字幕や画面のかっこに入れる**（例：声「切り札の薬」→ 字幕「切り札の薬（カルバペネム系）」）
- 一般の人への一言は、**医療アドバイスにしない**。「抗菌薬を、なぜ適切に使わなければいけないのか。それを知ることは、抗菌薬を処方された人の理解にもつながる」くらいにとどめる（作者の方針）。「飲み方」などの指示は書かない
- 「狭い薬へ」ではなく「**切り札を使わずに、その細菌に合う薬へ**」と言う（適正の自動操作は、大腸菌などにまず第3世代セフェムを使う。いまのデータでは、狭い薬（ABPC・CEZ）が大腸菌に効く割合は低いため。作者の判断：動きはそのまま、言い方を直す）
- 「患者・症例・病棟」の語は使わない（前からの決めごと）。数値の言い切りや診療の指示も書かない

## 3. ゲームの文案

- **タイトル**：ロゴの下に「選択圧（せんたくあつ）から」。説明の文に「抗菌薬（いわゆる抗生物質）は細菌を倒す薬。細菌ごとに効く薬が違い、使うほど『薬が効かない細菌』が残って増えます（選択圧）。」を足す。「はじめての人へ」のボタンを足す
- **遊び方**：はじめに絵の3枚（1画面1つ）。いまの詳しい説明は「くわしく」に畳む
  1. **細菌を、抗菌薬で倒す**：細菌が、膀胱（おしっこをためる袋）に向かってきます。下の手札から抗菌薬を選んで、兵士として呼び出し、倒します。膀胱に細菌が入ると耐久が減り、0 になると負けです
  2. **細菌ごとに、効く薬が違う**：ほとんどの細菌に効く「切り札」（機械兵の姿。カルバペネム系）と、ねらいをしぼった薬があります。はじめは細菌の正体が分かりません。遠くでは顕微鏡で見た色と形だけ、近づくと名前、さらに近づくと効かない薬が分かります（実際の検査の結果が、時間差で届くのと同じです）
  3. **使うほど、効かない細菌が残る**：薬を使うと、効く細菌は倒れ、効かない細菌だけが残って増えます（選択圧）。切り札ばかり使うと、2050年に、自分が残した細菌が攻めてきます。細菌の正体が分かったら、切り札を使わずに、その細菌に合う薬へ切り替えましょう
- **カード**：一般名を読めるようにする。切り札（MEPM・IPM/CS）に「切り札」の札。Access に「まず使う薬」、Watch に「使いすぎ注意」を一言で（WHO の AWaRe 分類）
- **盤面の札**：「耐性：」→「効かない：」、「自然耐性：」→「もともと効かない：」。字を大きく、膀胱やレーンの線に重ならないように
- **波が片付いたときの帯**：「波2が片付いた：薬が効く細菌は減り、効かない細菌が残った（選択圧）」と、その結果の耐性率の変化
- **結果画面のいちばん上に、原因の一文**（数字の詳しい表は下に）：
  - ステージ1で切り札が半分以上：「守り切りました。ただ、切り札（カルバペネム系）を {割合}% 使いました。効かない細菌が選ばれて残り、2050年に影響します。」
  - それ以外のステージ1：「守り切りました。いちばん使ったのは {系統}（{割合}%）でした。」（負けたときは「膀胱が破られました。」から）
  - 2050年に負けた：「膀胱が破られました。ステージ1でいちばん使った {系統}（{割合}%）が効かない細菌が増え、手札のどの薬も効かない細菌が {x}% 出てきました。」
  - 2050年を守った：「2050年も守り切りました。」
  - 数字（AHI・DASC/DOT・Access 薬の割合）には、どちらが良いかの一言を添える（例：AHI「1 に近いほど、偏らずに使えた」）
