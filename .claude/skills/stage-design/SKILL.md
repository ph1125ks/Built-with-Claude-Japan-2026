# ステージ設計の知識

ステージは、教える人の「教えたいこと」を、学生が遊んで体感できる形にしたもの。学生は「広く効く薬に頼ると、その場は勝てても2050年に効く薬がなくなる。菌の正体が分かるにつれて狭い薬に切り替えれば、未来も守れる」を体験する。

## 任せること・任せないこと

- **設計してよいもの**：手札（ステージ1と2050年）、医療費（はじめの額・1日ごとに増える額）、供給制限（毎回使えなくなる枚数と候補）、敵の波（時刻・レーン・菌の種類・数・間隔）、2050年までの年数、ブリーフィング（各200字以内）、振り返り（400字以内）、ステージの名前と id
- **変えてはいけないもの**：感受性の数値、菌と薬の性質（自然耐性・吸収率・投与間隔・薬価）。これらは公開データ（JANIS・厚生労働省の手引き・薬価基準）から作ったもので、ツールで読むだけにする。数値を作ったり、言い換えたりしない
- 文章に書かないもの：「患者」「症例」「病棟」の語、投与量の数値（mg など）、診療の指示（「〜を投与してください」など）。ゲームの中の説明として書く。実際の薬の選び方は、施設のアンチバイオグラムや国の手引きにもとづくことを添える

## ステージの形（JSON）

```json
{
  "id": "英小文字・数字・ハイフン",
  "title": "尿路（大阪府）",
  "region": "JANIS の地域名（全国 か 府県名）",
  "target": "病院実務実習の薬学生 など",
  "learningGoal": "教えたいこと（教える人の言葉を短く）",
  "debrief": "振り返り（400字以内）",
  "present": {
    "title": "いま",
    "briefing": "200字以内",
    "budget": 100, "budgetPerDay": 200, "bladderHp": 100,
    "hand": [{ "drug": "ABPC" }, { "drug": "CMZ" }],
    "shortage": { "count": 5, "candidates": ["ABPC", "CMZ"] },
    "waves": [{ "at": 2, "lane": "random", "species": "auto", "count": 4, "spacing": 2.0 }]
  },
  "future": { "title": "2050年", "yearsLater": 25, "...": "present と同じ項目" }
}
```

- `species`：`"auto"`（地域の尿の分離菌の割合で選ぶ）、菌の id（`ecoli`・`kpneumoniae`・`pmirabilis`・`paeruginosa`・`efaecalis`）、または `{ "mix": { "ecoli": 3, "efaecalis": 1 } }`（重み）
- `lane`：0〜2 か `"random"`。`at`・`spacing` は秒（ゲームの1日は24秒）
- 画面に並ぶ手札は8枚まで（手札の枚数 − 供給制限の枚数 ≤ 8）
- 既定ステージ `data/stages/uti-zenkoku.json` が合格した見本。迷ったら、これを写して少しずつ変える

## 合格の目安（SPEC.md 5.4。シミュレーションで確かめる）

| 目安 | 値 |
|---|---|
| 適正ボットは、いまも2050年も守り切る | どちらも 80% 以上 |
| 乱用ボット（広域薬を多用）も、いまは勝てる | 80% 以上 |
| 乱用ボットは、2050年に負ける | 30% 以下 |
| でたらめに選ぶより、適正に選ぶほうが強い | ランダム < 適正 |
| 何もしなければ負ける | 0% |
| 適正ボットの系統の使い分け（AHI） | 0.3 以上（仮） |
| 教えたい場面（例：CTRX が効かない大腸菌）が出てくる | ステージ1に平均2体以上 |

## 直し方の定石

- **適正ボットが負ける**：その菌に効く狭い薬を手札に足す。波の数・間隔をゆるめる。医療費を増やす。供給制限の枚数を減らす
- **乱用ボットが「現在」負ける**：広域薬（MEPM・TAZ/PIPC・LVFX）を手札に残す。波をゆるめる。医療費を増やす（広域薬は高い）
- **乱用ボットが2050年に勝ってしまう**：2050年の波を少し強くする（数を増やす・間隔をつめる）。2050年までの年数を延ばす。2050年の手札から、乱用で耐性が進んだ薬の代わりになる薬を減らす。MEPM は2050年にも残すと「乱用した薬が効かない」が見える
- **教えたい場面が少ない**：その菌が多く出るよう、波の `species` を `mix` にして重みを上げる（地域の割合から変えたことを振り返りに書く）。ただし乱用ボットの2050年の勝率が上がりやすいので、必ずシミュレーションで確かめる
- **AHI が低い（適正が1つの系統に偏る）**：同じ菌に効く別の系統の狭い薬を手札に足す。供給制限の候補を広げる（ただし TAZ/PIPC を候補にすると、適正ボットがカルバペネム系でつなぐようになる）
- 1回に変えるのは2〜3か所まで。変えたら必ずシミュレーションし直す
- 8回直しても満たせないときは、無理に合わせず、満たせない目安とその理由を正直に伝えて止まる

## 文章の書き方

- ブリーフィング：その地域の公開データから始まること、遠くはグラム染色・中ほどで菌名・近くで感受性が分かること、教えたいことに沿った一言。ゲームの言葉で、短く
- 振り返り：広域薬に頼ると2050年に効く薬が減ること、正体が分かったら狭い薬へ切り替えること、教えたいことの要点、「耐性化の速さはゲーム用に誇張」「実際の薬の選び方は施設のアンチバイオグラムや国の手引きにもとづく」
- 地域の数値（耐性率など）を文章に書くときは、ツールで得た値をそのまま、出典（JANIS 2025年報）とともに書く
- 感性率は、その地域の入院検体のすべての検査材料の集計で、尿だけの値ではない（尿から分かるのは菌の割合だけ）。「尿の大腸菌の感性率」とは書かず、「大阪府の大腸菌（入院検体・すべての検査材料）の CTRX 感性率」のように書く
- 感性率は菌全体の値。「CTRX が効かない大腸菌のうち CMZ が効く割合」のような、データにない値として書かない（「CMZ は大腸菌全体の感性率が 98% と高い」のように、何の値かが分かる書き方にする）
- CTRX が効かない大腸菌に CMZ へ切り替えるのは、カルバペネム系を温存するための選択で、効く範囲を狭める切り替え（デエスカレーション）ではない（ASC スコアは CMZ 7・CTRX 6）。「CMZ などの狭い薬へ」と書かない
- ゲームの結果（例：カルバペネム系を温存できる）を、現実の診療への言い切りとして書かない。「このゲームでは」と添える
