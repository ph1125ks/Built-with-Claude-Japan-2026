# データの出典と加工

このフォルダには、ゲームが使うデータがある。医学的な事実（感受性率・自然耐性・投与回数・吸収率など）と、ゲームの調整値（菌の HP や速さ、コストの段階など）を分けて持つ。

## フォルダの中身

| ファイル | 中身 | 種類 |
|---|---|---|
| `generated/janis-2025.json` | 菌×抗菌薬の感受性の株数（全国・近畿7府県）、尿から分離された菌の株数 | 公開データを加工したもの |
| `generated/prices-2026-11.json` | カードの薬の規格ごとの薬価と、1日量の薬価 | 公開データを加工したもの |
| `catalog/drugs.json` | 抗菌薬カード（系統・AWaRe 分類・ASC スコア・投与回数・吸収率・尿中移行・1日量） | 医学的な事実（作者が監修） |
| `catalog/bacteria.json` | 細菌（グラム染色の見た目・自然耐性）と、ゲームの調整値（HP・速さ・膀胱へのダメージ） | 医学的な事実＋ゲームの調整値 |
| `catalog/classes.json` | 抗菌薬の系統と、画面の色 | 分類 |
| `rules.json` | 感受性の変換ルール、代用、コストの段階、時間の速さ、耐性モデルの設定 | ルール（一部は作者が監修） |
| `stages/` | 開発用のステージ | ゲームの調整値 |

`generated/` は `npm run data:fetch` → `npm run data:build` で作り直せる。元の Excel（`raw/`）はリポジトリに入れない。手順はスキル `.claude/skills/janis-import/SKILL.md` にある。

## 加工の内容

- 菌は5種（大腸菌、肺炎桿菌、プロテウス・ミラビリス、緑膿菌、腸球菌（E. faecalis））に絞った
- 感受性は割合ではなく株数を持ち、使うときに割合を計算する（丸めのずれを避けるため）
- 「効く確率」は **S の株数 ÷ 合計**（I・R・SorI・IorR・判定不能は効かない扱い。作者の決定）。変換ルールは `rules.json` の `susceptibility`
- JANIS に値がない組み合わせは、代用か固定値で扱う（`rules.json` の `proxies`。根拠は各項目の basis）
  - 経口第3世代セフェム（セフジニル）の感受性 → CTX の値で代用（EUCAST では経口第3世代セフェムの感性の基準が CTX・CTRX と同じで、耐性の基準はより厳しい）
  - 腸球菌の TAZ/PIPC → ABPC の値で代用（EUCAST の推定ルールは「ABPC 耐性なら PIPC も耐性」の向きだけで、感性の向きは近似。EUCAST では野生株の E. faecalis の TAZ/PIPC は「I（増量投与で感性）」の扱い）
  - 腸球菌の MEPM → 効かない扱い（EUCAST のブレイクポイント表で「-」＝治療に適さない）
  - 内服 AMPC → ABPC の値で代用（EUCAST v16.1：単純性尿路感染症では内服アモキシシリンの基準が ABPC と同じで、ABPC から推定する。腎盂腎炎など尿路由来のほかの感染症では I の扱いになる。監修待ち）
  - 内服 CEX → CEZ の値で代用（JAID/JSC の記載による。EUCAST にあるのは CEX から CEZ を推定する逆の向きだけ。監修待ち）
  - 腸球菌の IPM/CS → 効かない扱い（JANIS に値がなく、EUCAST では野生株を S と報告しない。ABPC に感性でもイミペネムは予測できない：Expert Rules v3.2 Rule 1。監修待ち）
  - プロテウスの IPM/CS は JANIS の値をそのまま使う（全国で S 55.2%、I が多い。EUCAST v16.1 は Proteus など Morganellaceae にはイミペネムの活性がもともと低いとしている：印刷 p.17 注2）
- 自然耐性は、データにかかわらず効かない扱い（`catalog/bacteria.json` の `intrinsicResistance`）
  - EUCAST「Expected Resistant Phenotypes v1.2」の表と照らして確かめた（各菌の sources に表・Rule 番号・ページ）
  - 緑膿菌の CMZ と経口第3世代セフェム（セフジニル）は EUCAST の表に個別の記載がない。EUCAST v16.1 の緑膿菌の表で、同じ系統のセフォキシチン（セファマイシン系）と経口第3世代セフェム（セフィキシム・セフポドキシム・セフチブテン）が「-」（治療に適さない）であることから耐性とした
- 投与回数と1日量は、手引きの記載に合わせた（9剤）。経口第3世代セフェム（セフジニル）は電子添文に合わせた。2026-11-03 に足した5剤は、CAZ が手引きの表、AMPC・CEX が手引き 歯科編の表と電子添文、IPM/CS・CTX が JAID/JSC 感染症治療ガイド2023（5剤とも監修待ち）
- 吸収率：LVFX はインタビューフォームの経口と点滴静注の AUC の比（0.98。別々の被験者群の平均どうしの比で、IF が吸収率として示した数値ではない）、セフジニルは手引き 歯科編 表9 の 20〜25% の上限（0.25）、アモキシシリンは同じ表の 74〜92% の上限（0.92）、セファレキシンは同じ表の 90%（0.9）
- 尿中移行の係数は全薬 1.0（作者の決定。文書から出る結論ではなく、ゲームとしての判断）。参考：LVFX は72時間で投与量の約84%が未変化体として尿中へ（IF p.59）、セフジニルは24時間の尿中排泄率が約26〜33%（電子添文 16.5）。ほかの薬の値は未取得
- 割合は株数から計算し、データの段階では丸めない。画面に出すときだけ小数1桁に丸める
- 耐性の連動（`rules.json` の `linkedResistance`）：腸内細菌目で CTRX に耐性の個体は、ABPC・AMPC・CEZ・CEX・CTX・CAZ・経口第3世代セフェム・CFPM にも耐性にする（ESBL の分解の範囲と、ESBL なら CFPM は選択肢にならないという手引きの記載による。CFPM を入れたのは作者の決定。2026-11-03 に足した AMPC・CEX・CTX・CAZ は監修待ち）
  - 薬ごとの全体の耐性率はデータの値のまま。ただし連動する薬の耐性率は CTRX の耐性率を下回れないので、経口第3世代セフェムと CFPM の耐性率は CTRX 以上になる（全国の大腸菌では、CTX で代用した経口第3世代セフェムと CTX が 28.9% → 31.9%、CFPM が 20.4% → 31.9%、CAZ が 20.3% → 31.9%。いちばん大きく変わるのはプロテウスの CAZ：4.8% → 29.1%）
- カルバペネム耐性（CRE）の連動（`rules.json` の `linkedResistance` の2つめ。作者の確認待ち）：腸内細菌目で MEPM に耐性の個体は、CTRX・CMZ・TAZ/PIPC にも耐性にする。CTRX の連動を通して、ABPC・AMPC・CEZ・CEX・CTX・CAZ・経口第3世代セフェム・CFPM にも耐性になる。IPM/CS も連動させる（作者の決定、2026-11-03）。LVFX・AMK は連動させない
  - 連動は菌ごとに木にしている（MEPM → CTRX → ABPC など）。1つの薬に親は1つだけで、木の上から順に「親に耐性なら子も耐性、そうでなければ全体の耐性率が表の値になる確率」で決める
  - 開始時の表では腸内細菌目の MEPM の耐性率が 1% 未満なので、表の値は変わらない。耐性モデルで MEPM の耐性率が上がる未来ステージで効いてくる
  - LVFX と AMK は、必ず耐性にする根拠がないので連動させない（p.19）。CRE の中での感性率は文書に数値がないので、全体の率と同じにしている（単純化。実際より効きやすく出る可能性がある）
  - 単純化：MEPM に効かない個体を CRE とみなしている。新しい β-ラクタム系の薬はカードにない。緑膿菌は連動させていない
- 抗菌薬を優先して使う順（`rules.json` の `stewardship`）：AWaRe の群（Access → Watch → Reserve）で決め、同じ群ではカルバペネム系とフルオロキノロン系を後に回す。同じ順位どうしは、尿から出る菌全体への効く見込み（カバー率）が低いほうを先に使う
  - AWaRe は耐性化したときに困る度合いによる分類で、使う順に当てはめるのはゲームとしての判断（手引きにこの使い方は書かれていない）
- 単純化：CTRX 耐性を ESBL とみなしている。手引きによれば、セフォタキシム耐性の株の多くは ESBL 産生菌とみられるが、すべてではない。プラスミド性 AmpC で CMZ も効きにくくなる場合は表していない
- 菌の出現割合は、尿から分離された菌の株数を、この5種の中で割り直したもの
- 1日量の薬価は、同じ規格の薬価の最小値 × 1日に使う規格単位の数（`catalog/drugs.json` の `dosing`）。AMK だけは、1日 900mg を実際に使う管の組み合わせ（200mg 管 × 4 ＋ 100mg 管 × 1。`price.plus`）で数える（2026-11-03 作者の判断）。製品名（商標）はゲームには出さない
- 医療費の方式は、現実の薬価基準による薬価方式（2026-11-03 作者の判断：広くて安い薬（内服 LVFX）が選びやすいのは不適正使用につながる現実の特徴で、高くても ABPC を選ぶべき場面もある）

## 耐性化のモデル（ゲームの決めごと）

開始時の耐性率は公開データ（上の加工のとおり）。そこからの変化は、文書から出る値ではなく、ゲーム用の式と係数で決める（`rules.json` の `resistance`、式は `src/engine/resistance.ts`）。どちらのモデルも、変えたあとに連動（ESBL・CRE）の下限をかけ直す。

- **A（選択圧の再現）**：波が片付くたびに、その波の菌について、薬ごとに「さらされた割合」（2秒以上さらされた個体を1と数える）を出し、耐性のオッズの対数を「誇張係数 × 0.25 × さらされた割合」だけ上げる。耐性菌が少ないうちはゆっくり、増えると速く上がる。耐性率が 0.1% 未満の組（0% を含む）は、さらされたときに 0.1% として上げ始める。実際に生き残った個体ではなく、いまの耐性率（期待値）で計算する。公開データで同じ値を使っている組（内服 AMPC と ABPC、内服 CEX と CEZ、経口第3世代セフェムと CTX）は、代用している菌に限り、どちらにさらされても同じ薬にさらされたとみなし、同じだけ上げる（2026-11-03 作者の判断。`A.sharedSelection`）
- **B（耐性ゲージ）**：召喚するたびに、系統のゲージに「誇張係数 × 広さ（カバー率）÷ 1日の投与回数」がたまる。4 たまるごとに、その系統の薬について、まだ効いている菌の 10% を耐性にする
- **未来ステージ（2050年）**：データの年（2025）から25年後。ステージ1と同じ使い方が「年数 × stagesPerYear（A 0.25、B 1.2）」回分続いたとみなし、ステージ1での変化を、A はオッズの対数、B はまだ効いている割合の対数のまま延ばす
- 係数は、開発用のステージでボットの勝率を比べて決めた仮の値（`docs/DEVLOG.md`）。A と B のどちらを使うかは作者が決める
- 2050年までの1年あたりの上がり方は、厚生労働省「薬剤耐性ワンヘルス動向調査年次報告書 2024」（NAOR 2024、令和7年3月14日）の JANIS の耐性率の推移（2014〜2023年）で、このゲームに出てくる菌と薬の組み合わせ（CTRX は CTX の値で見た）の中でいちばん速く上がった組を上限にした（`carryOver.maxLogitPerYear`、誇張の倍率 1）。いまは肺炎桿菌の CAZ（表2 p.18：3.8% → 11.7%、オッズの対数で年 0.144）。CAZ をカードに足す前は肺炎桿菌の CFPM（3.5% → 9.7%、年 0.124）で、2026-11-03 に作者の方針（根拠のある実測の値を採る）で、定義どおり 0.144 に上げた。組ごとの傾きは、10年分の値のオッズの対数を最小二乗で直線にあてはめて出した。使い方によっては、上がった組の多くがこの上限の速さで延びる（モデル B ではほぼすべて。モデル A の適正な使い方では約4割）ので、多くの組では実測（例：大腸菌の LVFX 年 0.011、CTX 年 0.019）より速い
  - 2026-11-02 には AMR Review（2014年）の RAND の前提（15年で耐性率100%）を目安にしていたが、極端すぎるとの作者の判断で、公的な実測の上限に替えた（2026-11-03）
- **使わなかった薬の下がり方**（2026-11-03、作者の判断。`carryOver.declineWhenUnused`）：ステージ1で一度も使わなかった薬（使用日数 0）で、ステージ1の中で上がらなかった組（連動などで上がった組は除く）は、2050年への引き継ぎでだけ、NAOR 2024 で耐性率がはっきり下がっていた組に限り、その組の実測の傾き（オッズの対数、年あたり）で下げる。上限は、ゲームの菌×薬で実測でいちばん速く下がった組（緑膿菌の AMK：1.9% → 0.6%、年 −0.128）。下げるのは、緑膿菌の6組（TAZ/PIPC −0.015、CFPM −0.041、IPM/CS −0.042、MEPM −0.054、AMK −0.128、LVFX −0.064。IPM/CS は 2026-11-03 に足した。緑膿菌の CAZ は −0.004 で丸めの範囲でも負だが、下がったのは 2014 → 2015 だけなので外した）、腸球菌の LVFX（−0.060）、大腸菌の CMZ（−0.032）、肺炎桿菌の CMZ（−0.031）・MEPM（−0.063）。表の値は 0.1 刻みに丸められているので、丸めの幅（±0.05）で各年の値を動かしても傾きが負のままの組だけを使った。大腸菌の MEPM（0.2% → 0.1%）・AMK（0.2% → 0.1%）と腸球菌の ABPC（0.3% → 0.2%）は、丸めの範囲では上がったとも下がったとも言い切れないので外した（大腸菌と肺炎桿菌の IPM も同じ理由で外した。腸球菌の TAZ/PIPC と、内服 AMPC・CEX は代用しているので、これも下げない）。実測で上がっていた組、変わらなかった組（肺炎桿菌の AMK）、表にない組（プロテウス、CTRX・経口第3世代セフェムは CTX で見ると上がっている）も下げない。ステージ1の中では下げない。実測は薬が使われ続けた中での変化で、使わなければ下がると示したものではない（当てはめはゲームの決めごと）
- **系統の偏り**（`balance`）：ステージのこれまでの使用日数のうち、その系統の割合が 25% を超えると選択圧が強まり（最大2倍）、下回ると弱まる（最小0.5倍）。倍率 ＝（割合 ÷ 0.25）^ 0.5。使用日数の合計が1日分に届くまでは倍率をかけない。考え方は AHI（抗菌薬選択圧指数）。ASP ガイダンス2024 p.120 に名前と文献11・12（Takesue ら 2010、Ueda ら 2023。題名から、系統を偏らせない使い方と耐性菌の関係を扱う論文）があり、有用性は今後の検討課題とされている（p.118 f）。式と係数はゲームの決めごとで、AHI の定義や基準の値を文献から採ったものではない（2026-11-03 作者の判断：文献の本文での確認や作者の研究の式に合わせることはせず、ゲームの決めごととして明記する）。手札の系統が多いと、均等に使っても倍率は1未満になる（7系統なら各14%で 0.76）
- AMR Review の1,000万人と GBD 2021（Lancet 2024）の2050年の死亡数の予測は、画面の注記と出典にだけ使い、耐性率の計算には使っていない
