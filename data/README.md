# データの出典と加工

このフォルダには、ゲームが使うデータがある。医学的な事実（感受性率・自然耐性・投与回数・吸収率など）と、ゲームの調整値（菌の HP や速さ、コストの段階など）を分けて持つ。

## フォルダの中身

| ファイル | 中身 | 種類 |
|---|---|---|
| `generated/janis-2025.json` | 菌×抗菌薬の感受性の株数（全国・近畿7府県）、尿から分離された菌の株数 | 公開データを加工したもの |
| `generated/prices-2026-11.json` | カードの薬の規格ごとの薬価と、1日量の薬価 | 公開データを加工したもの |
| `catalog/drugs.json` | 抗菌薬カード（系統・投与回数・吸収率・尿中移行・スペクトラムの順位・1日量） | 医学的な事実（作者が監修） |
| `catalog/bacteria.json` | 細菌（グラム染色の見た目・自然耐性）と、ゲームの調整値（HP・速さ・膀胱へのダメージ） | 医学的な事実＋ゲームの調整値 |
| `catalog/classes.json` | 抗菌薬の系統と、画面の色 | 分類 |
| `rules.json` | 感受性の変換ルール、代用、コストの段階、時間の速さ、耐性モデルの設定 | ルール（一部は作者が監修） |
| `stages/` | 開発用のステージ | ゲームの調整値 |

`generated/` は `npm run data:fetch` → `npm run data:build` で作り直せる。元の Excel（`raw/`）はリポジトリに入れない。手順はスキル `.claude/skills/janis-import/SKILL.md` にある。

- e-Stat のコンテンツは、政府標準利用規約（第2.0版）に準拠した利用規約に従う（CC BY 4.0 と互換）。数値データは著作権の対象外とされている
- 厚生労働省ホームページのコンテンツは、公共データ利用規約（第1.0版）に従う（CC BY 4.0 と互換）
- どちらも、出典を書き、加工した場合はその旨を書く。このリポジトリのデータは、上の出典を加工して作成したもので、厚生労働省や JANIS 事務局が作成したものではない
- 規約の読み方は作者の判断であり、法的な助言ではない
- コードのライセンスと、このデータの利用条件は別である

## 加工の内容

- 菌は5種（大腸菌、肺炎桿菌、プロテウス・ミラビリス、緑膿菌、腸球菌（E. faecalis））に絞った
- 感受性は割合ではなく株数を持ち、使うときに割合を計算する（丸めのずれを避けるため）
- 「効く確率」は、いまは **S の株数 ÷ 合計**（I・R・SorI・IorR・判定不能は効かない扱い）。変換ルールは `rules.json` の `susceptibility`
- JANIS に値がない組み合わせは、代用か固定値で扱う（`rules.json` の `proxies`）
  - 経口第3世代セフェム（セフジニル）の感受性 → CTX の値で代用
  - 腸球菌の TAZ/PIPC → ABPC の値で代用
  - 腸球菌の MEPM → 効かない扱い（値がないため）
- 自然耐性は、データにかかわらず効かない扱い（`catalog/bacteria.json` の `intrinsicResistance`）
  - 根拠にする基準：CLSI M100 の Appendix B「Intrinsic Resistance」と、EUCAST の「Expected Resistant Phenotypes」。原文との突き合わせは作者の監修で行う（いまは仮）
  - 緑膿菌の経口第3世代セフェム（セフジニル）は、どちらの基準にも個別の記載がないとみられ、系統からの推論で耐性としている
- 投与回数・吸収率・尿中移行は、各薬の添付文書とインタビューフォームを出典にする（いまは仮。作者の監修で確定し、出典をここに書く）
- 割合は株数から計算し、データの段階では丸めない。画面に出すときだけ小数1桁に丸める
- 菌の出現割合は、尿から分離された菌の株数を、この5種の中で割り直したもの
- 1日量の薬価は、同じ規格の薬価の最小値 × 1日に使う規格単位の数（`catalog/drugs.json` の `dosing`）。製品名（商標）はゲームには出さない

## 注意

- 判定基準は CLSI 2012 で、現在の臨床検査の基準とは違う
- 「すべての検査材料」の表は、尿から出た株だけの集計ではない
- 国内のすべての医療機関の集計ではない
- 耐性化の速さはゲーム用に誇張している（耐性モデルは `rules.json` の `resistance`）
- このゲームは教育用のシミュレーションで、実際の診療の判断には使えない
